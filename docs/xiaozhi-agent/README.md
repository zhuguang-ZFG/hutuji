# 小智云智能体配置（让对话更聪明）

> 目标：小智云负责「听懂 + 选工具」；绘图质量仍由京东云 MCP + FreeModel 决定。  
> 本目录是**可粘贴到控制台**的文稿，不含密钥。

## 控制台操作顺序

1. 打开 [xiaozhi.me 控制台](https://xiaozhi.me/) → 对应智能体 → **配置角色**。  
2. 将 [`role-prompt.md`](./role-prompt.md) 全文（或主体）粘贴进角色/系统提示。  
3. **知识库**（若控制台有「我的知识库」）：  
   - 新建知识库，名称建议：`hutuji写字机`  
   - 上传 [`knowledge-base.md`](./knowledge-base.md)（或粘贴为文本文档）并同步  
   - 在智能体编辑页 **关联该知识库**  
   - 用召回测试关键词：`画一只猫`、`换纸`、`写字机忙`、`单线笔画`  
4. 确认 **MCP 接入点** 已连上京东云桥接（`hutuji_draw` / `hutuji_status` / `hutuji_preview_svg` 可见）。  
5. 语音试一句：「画一只侧脸简笔小猫」→ 应调用云端 `hutuji_draw`，description 简洁。

> 官方云 UI 可能改版：若找不到「知识库」，至少完成第 2、4 步；知识库文稿仍可作角色补充材料手工粘贴。

## 两层脑（勿混）

| 层 | 谁 | 变聪明靠什么 |
|----|-----|--------------|
| 对话/意图 | 小智云 | 角色提示 + 知识库 +（可选）更强对话模型 |
| 出图 | 京东云 MCP `llm_svg.py` | `SYSTEM_PROMPT` + FreeModel / 其它 LLM |

## 验收话术

| 你说 | 期望 |
|------|------|
| 画一只站在树枝上的小鸟 | 调 `hutuji_draw`，description≈「单线简笔小鸟站在树枝上」 |
| 写字机在忙吗 /  generat 服务怎样 | 调 `hutuji_status`（云端）或设备 `hutuji.status` |
| 别画了 / 停下 | 调 abort / 诚实说明换纸中可能停不了 |
| 画个照片级写实油画猫 | 拒绝或改写成单线简笔，不承诺填色写实 |
