# 小智云智能体配置（让对话更聪明）

> 目标：小智云负责「听懂 + 选工具」；绘图质量由京东云 MCP + **llm7**（现行）决定。  
> 本目录是**可粘贴到控制台**的文稿，不含密钥。  
> **进度（2026-07-26）**：京东云桥接已连；知识库文稿**已上传**。请确认智能体页已**关联**该库，并补角色提示（若未贴）。

## 控制台最短步骤

1. 打开 [xiaozhi.me 控制台](https://xiaozhi.me/) → 对应智能体 → **配置角色**。  
2. 将 [`role-prompt.md`](./role-prompt.md) 全文粘贴进角色/系统提示 → 保存（若已贴可跳过）。  
3. **知识库**：✅ 已上传 [`knowledge-base.md`](./knowledge-base.md) → 智能体页确认 **已关联** → 可选召回测：`画一只猫` / `换纸` / `写字机忙`。  
4. **MCP 接入点**：✅ 已写入京东云并启桥接 → 控制台刷新，应见 `hutuji_draw` / `hutuji_status` / `hutuji_preview_svg`。  
5. 语音试一句：「画一只侧脸简笔小猫」→ 应调云端 `hutuji_draw`。

> 官方云 UI 可能改版：若找不到「知识库」，至少完成第 2、4 步；知识库文稿仍可作角色补充材料手工粘贴。
