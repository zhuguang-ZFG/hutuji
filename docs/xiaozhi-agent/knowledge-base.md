# 丹青知识库（上传到小智「我的知识库」）

文档用途：供智能体检索，回答「能画什么、怎么画、不能做什么、工具怎么用」。

## 产品是什么

**丹青**（内部代号呼图机/hutuji）是一台 **AI 智能绘图机**：对它说话，它就帮你画出来——语音指令 → 云端 AI 生成绘图 → 机器自动落笔，画完自动停笔；取下画好的纸、放上新纸就能继续。

它有两颗芯片协同工作：一颗负责听你说话和理解意图（ESP32-S3 小派），另一颗负责精确控制画笔运动（ESP32 Grbl）。两颗芯片通过 WiFi 通讯。

## 能画什么

呼图机擅长 **线条艺术**——用一支笔描绘轮廓和线条，风格类似速写、简笔画、线描插画。

### 特别适合画的

- **动物**：小猫、小狗、小鸟、兔子、鱼、蝴蝶等简笔轮廓
- **植物**：花朵、树木、叶子、仙人掌、向日葵的线描
- **日常物品**：自行车、杯子、房子、汽车、灯泡、雨伞
- **人物剪影**：侧脸轮廓、人物站姿/坐姿剪影
- **场景小品**：树枝上的鸟、窗边的花瓶、月亮和星星
- **文字书法**：汉字、英文字母（单线书法风格；「福」字这类大字实测效果稳定）
- **几何图案**：星星、心形、雪花、简单曼陀罗

### 画不了的

- 照片级写实（没有阴影渐变）
- 填色/涂色（只有线条）
- 油画/水彩效果
- 大面积色块
- 精细像素画

遇到画不了的需求时，建议用户换成线条风格的替代方案。

## 出图前准备（笔架归位）

- **每次开机、断电重启或搬动过机器后，第一次出图前**：用手把笔架往**左下角**推、推到底（推到机械死点）。机器没有限位感应，靠这一下确定画图原点；不推的话画面会偏。
- 推一次就够：之后连续出图都不用重复推。
- 抬笔落笔（Z 方向）机器会自动校准，用户不用管。

## 用户怎么说效果好

### 好的说法（推荐）

- 「画一只小猫」→ AI 自动补全为合适的线描风格
- 「画朵向日葵」
- 「画个自行车」
- 「画一只站在树枝上的小鸟」
- 「写个大大的福字」
- 「画个简笔画的小房子，旁边有棵树」
- 「画一条鱼，侧面的」

### 不太好的说法

- 「画得像照片一样真实」→ 建议改成线描风格
- 一次要求画整个故事 → 建议拆成一幅一幅来
- 含大量参数/色值 → 提醒只有黑白线条

### AI 怎么补全

用户说的往往很简短，AI 应补全成适合线描绘图的描述：
- 「画个猫」→ description：`单线简笔小猫，侧面站姿，留白构图`
- 「来朵花」→ description：`一朵盛开的花朵线描，花瓣舒展`
- 「画条鱼」→ description：`单线简笔小鱼，侧面游动姿态`

## 工具清单（云端 MCP）

### hutuji_draw

- **何时用**：用户要画图、出作品时。  
- **参数 description**：简短中文绘画主题（建议带「单线」「简笔」「线描」）。  
- **结果与衔接**：按返回形态分两种。生产异步模式返回 `accepted: true`，表示已受理、正在后台生成；完成后服务器会自动调用设备侧 `hutuji.draw` 把预览推上屏，助手不要再次调用 `hutuji.draw` 或 `hutuji.confirm`。同步模式下返回 `url` 与 `preview_url`；若服务端已配置设备消息 token，也会在唯一完成点自动尝试调用 `hutuji.draw`，助手不要重复推送，只有预览未自动出现时才把两个地址一起传给设备侧 `hutuji.draw`。用户看过预览并明确确认后再调 `hutuji.confirm`。两种模式都必须预览确认后才真正落笔；不要编造 URL、不要重复触发同一主题的生成。用户在预览出现前说取消时，不能假装已取消；待预览出现后再调设备侧 `hutuji.abort`。

### hutuji_status

- **何时用**：用户问云端生成服务是否正常。  
- **不要**用它代替设备实时状态查询（那是设备侧 `hutuji.status`）。

### hutuji_preview_svg

- **何时用**：只看矢量草稿效果、不要马上出纸。  
- 调试用，不触发丹青运动。

## 工具清单（设备侧，S3）

### hutuji.status

查询丹青的连接状态：是否连通、Grbl 是否就绪、是否已授权、当前任务状态。

### hutuji.draw

参数 `url` + `preview_url`（缺一不可）：先把预览图上屏（不动纸），用户确认后才下载该 url 的 G-code 并逐行转发给丹青。**预览 + 确认两步才是真正出图**——云端 `hutuji_draw` 只生成两个地址，须由助手传入本工具；漏调则纸不动。

### hutuji.abort

尝试中止当前任务。中止后这一幅不会续画，需如实告知用户。

### hutuji.pause / hutuji.resume

- **暂停**：用户说「暂停」「等一下」「先停一下」时调用 `hutuji.pause`。笔会停在原地，进度不丢。
- **继续**：用户说「继续」「接着画」时调用 `hutuji.resume`，从暂停处接着画。
- **区别**：不要把「暂停」误用成 `hutuji.abort`；abort 会放弃当前任务，pause 可以继续。
- **暂停有时限**：暂停超过约 10 分钟，设备会自动取消这一幅（抬笔、任务结束）；之后再说「继续」已无法接续，需重新画。

### hutuji.repeat

用户说「再画一张」「一样的再来一次」时调用。设备复用上一张的 G-code，不重新生成。画完自动停笔；想连着画，先取纸放新纸；如果还没有成功画过上一张，工具会返回错误。

### hutuji.pen_test

用户怀疑笔没墨、没有触纸或要求试笔时调用。机器会落笔停 1 秒再抬笔；随后提醒用户检查纸上是否留下点迹。

### hutuji.manual

用户想手动挪笔架、微调位置或检查笔时调用：`jog_x+/jog_x-/jog_y+/jog_y-` 点动（先用 `jog_step_1/jog_step_10` 选 1mm/10mm 步距）、`pen_up/pen_down` 抬落笔、`home` 回原点。仅空闲可用；返回 started 表示已开始执行，完成后设备会播报。维护动作（设原点/解锁/关电机/重启）语音不开放，引导用户在机器屏幕上操作。

## 常见问题

**Q：为什么画出来都是线条？**  
A：呼图机是线描绘图机，用一支笔勾勒轮廓，这就是它的风格特色——像速写和简笔画。

**Q：能不能画彩色的？**  
A：目前只支持单色线条。可以换不同颜色的笔芯，但同一幅画只有一种颜色。

**Q：我说了画，它怎么没动？**
A：先按返回形态排查：异步模式收到 `accepted` 后先查云端 `hutuji_status`，确认是否仍在生成；同步回落若已有 `url`/`preview_url`，检查是否已把两个地址传给设备侧 `hutuji.draw`。预览已上屏但纸不动，检查用户是否说「开始画」以及设备 `hutuji.status` 是否为 `awaiting_confirmation`；预览还没出现不要调用 `hutuji.confirm`。`last_draw_error` 只表示最近一次云端任务失败，只有明确对应当前主题时才按失败处理，不能仅凭非空就自动重画；需要重试时等用户明确要求再重新调用 `hutuji_draw`。其余再查设备是否连上丹青、纸张和授权。

**Q：没纸了会怎样？**  
A：机器不会提前拦你——笔下面有纸就画。画完一页会自动停笔，**不会自动换纸**：取下画好的纸、平整放上一张新纸，再说一次要画的内容就行。纸卡住了会提示检查纸张，整理好再试。

**Q：画得很淡、有断线怎么办？**  
A：可能是笔芯快没墨或笔没触到纸。先说「试一下笔」让机器落笔试一下：纸上有清晰点迹说明笔没问题（可能是构图太细，换个大轮廓主题重画）；点迹很淡或没有，就该换笔芯了。

**Q：画太复杂会怎样？**  
A：云端有内容校验，太复杂可能失败。建议换个更简洁的描述再试。

**Q：正在画能不能停？**  
A：可以说「停下」。设备会尽快中止；画到一半中断的不会续画，要如实告知。

**Q：它能连续画很多张吗？**  
A：可以！画完一张会自动停笔，放好新纸后说下一个主题就继续画。

**Q：画的大小怎么控制？**  
A：云端按固定可画区域生成，用户通常无需指定尺寸；如果要求超出范围，会拒绝整幅生成并说明原因，不会裁剪或静默缩放。

**Q：说完要等多久才开始画？**  
A：看主题。常见主题（小猫小狗、水果、交通工具这些，内置了几百种简笔画图库）**几秒就能出稿**；要 AI 现场创作的主题（没见过的东西、复杂场景）通常 10~40 秒。生成好后丹青才开始落笔。等的时候不用重复说，重复说会重新排队。

**Q：同一个主题画两次，会一模一样吗？**  
A：不会。AI 每次创作都有变化，同样的话两次画出来的构图会不同。想要一模一样的一张，说「再画一张」（复用上一张的图稿）；想要同主题换个画法，说「换个姿势/换个构图」。

**Q：画面在纸上的位置和大小能指定吗？**  
A：不用指定。云端会自动把主体**居中并留好边距**（四周约 10mm），太小会放大、太大会收小，但不会超出可画区。

**Q：为什么提示「太复杂」或生成失败？**  
A：两种情况：①主题细节太多，超过单线稿能表达的上限，云端会拒绝并说明，换个更简洁的描述即可；②生图服务临时繁忙，等一两分钟再试就好。

## 语音识别纠错（听不准时据此猜回意图）

语音转文字常把同音/近音字认错。遇到下表左列或类似怪词时，按右列理解意图，必要时反问一句确认：

| 语音可能被识别成 | 真实意图 |
|---|---|
| 花一只猫 / 划一只猫 / 话一只猫 | 画一只猫 |
| 画朵火 / 话朵花 / 滑朵花 | 画一朵花 |
| 在来一张 / 再来一涨 | 再来一张（重画/换主题） |
| 听下 / 挺下 / 停一下下 | 停下 / 暂停 |
| 接着话 / 继续话 | 继续画 |
| 画个福子 / 画个胡子（语境为写字时） | 写/画个「福」字 |
| 开始晃 / 开始放 / 开始话 | 开始画（确认出图） |
| 换一只猫 / 换一只狗（语境为想重画换主题） | 换一张/换个主题 |
| 落比 | 落笔（手动控制：让笔落纸） |
| 排比 | 抬笔（手动控制：让笔抬离纸） |
| 布距 | 步距（点动步长，1/10 毫米两档） |

兜底原则：上表只是高频示例，没列到的怪词同样先按最接近的绘图意图猜，猜不准就反问「你是想画___吗？」，不要直接画错或报错。

## 硬件规格

**纸张**：标准 A4 打印纸（210×297mm），横向放置——X 轴沿纸的长边（297 方向），Y 轴沿纸的宽边（210 方向）。可画区域约 **190×277mm**（X≤277 沿长边、Y≤190），四周留约 10mm 边距；任一坐标越界时云端会拒绝整幅生成并说明原因，不会裁剪或静默缩放，所以构图别顶到纸边。

**画笔**：标准记号笔/签字笔，笔芯可更换。默认黑色，换不同颜色笔芯可画其他颜色，但同一幅画只有一种颜色。

**速度**：一幅简笔画大约 1-3 分钟，复杂线描可能 5-8 分钟。速度由丹青运动控制决定，软件无法调快。

**换纸**：不支持自动换纸。画完一张自动停笔；想连续出图，取下画好的纸、平整放上新纸即可。

**精度**：笔触精度约 0.1mm，足以表现细节丰富的线描。

## 故障排查

**Q：说了画但没反应**  
A：依次排查——① 云端：调 `hutuji_status` 看 MCP 服务是否正常；② 设备端：调 `hutuji.status` 看丹青是否在线；③ WiFi：检查丹青网络连接；④ 纸张：可能缺纸了；⑤ 授权：丹青可能未授权。

**Q：画到一半停了**  
A：可能是 WiFi 断连。丹青**不会从断点续画**——网络恢复后它会用缓存从这一幅的开头重画（已画过的部分会重走一遍）。如果长时间不动，调 `hutuji.status` 查看状态。

**Q：画的线条很粗/很淡**  
A：这和笔芯有关，不是软件能控制的。换支好笔或新笔芯就行。

**Q：纸卡住了**  
A：别硬拽！关电源，手动取出纸张，重新放好纸再开机。

**Q：丹青一直嘟嘟叫**  
A：可能在等授权或者报错了。看看面板灯的状态，或者调 `hutuji.status` 问问。

**Q：画偏了 / 画到纸外面去了**  
A：几乎都是笔架没归位。这台机器没有限位感应，开机后要先手动把笔架推到**左下角推到底**来定原点（见「出图前准备」）。断电或搬动过机器后都要重新推一次。

**Q：画出来的和我想的不一样**  
A：这是 AI 理解偏差，不是故障。把描述说得更具体一点（品种、姿势、朝向、要不要配角），或者说「换个构图」让它重来一版。

**Q：提示生成失败 / 服务繁忙**  
A：云端生图服务临时拥挤，稍等一两分钟重新说一遍即可；连续多次失败就调 `hutuji_status` 看服务状态并如实告知。

## 自助排查向导（用户报故障时按这个引导，一步一问）

用户说「坏了 / 不动了 / 画不了」时，**不要一口气把原因全念出来**。小派是售后服务助手：先问清症状，再像真人客服一样一步一步引导用户自己动手排查——每步只让用户做一件事、等他做完反馈，再决定下一步。先查软（状态、网络）再查硬（纸、笔、笔架），先易后难。三步排查仍不好，就收集好信息（哪一步出问题、面板灯什么状态、`hutuji.status` 返回什么）建议联系售后，并安慰用户「不是你用错了」。

**第 0 步（必做）：问症状**——「哪里不舒服呀？是说了没反应，还是画到一半停了，还是画得不对？」别跳过这步直接猜。

**症状 A：说了画但没反应（最常见）**
1. 先看屏幕：「屏幕上有没有出现预览图？」——有预览但纸不动：是不是还没说「开始画」？提醒「你说一声开始画，它就动笔啦」。连预览都没有：进第 2 步。
2. 查状态：调 `hutuji.status`——不在线就说「丹青失联了，帮我看看丹青的电源灯亮不亮？」电源不亮→插电开机；亮→第 3 步。
3. 查网络：「丹青背面 / 路由器是不是刚断过网？」引导用户看设备屏幕上的 WiFi 图标；断网就重启丹青（关机再开），等它自己连回来。
4. 查纸：「纸盒里还有纸吗？」没纸→放好纸再画。
5. 以上都正常还不行：调 `hutuji_status` 查云端；云端正常而设备不理，收集 `hutuji.status` 返回 + 面板灯状态，建议联系售后。

**症状 B：画到一半停了**
1. 先安抚：「别急，大概率是网络断了一下。」查 `hutuji.status` 看是否断连。
2. 断连过：如实说「它不会接着画，会从这一幅开头重画——网络好了跟我说，我让它重画一张」。
3. 没断连却停：可能是暂停状态——「你刚才说过暂停吗？说一声『继续』试试。」还不行就调 `hutuji.abort` 取消后重画。

**症状 C：画得不对（偏了 / 到纸外 / 一片乱线）**
1. 引导推笔架：「这台机器没有自动找位置的感应器。你把笔架用手往**左下角轻轻推到底**，听到咔哒声最好——推好了告诉我。」
2. 推完重画一张验证；还偏就检查纸有没有放歪、放平。
3. 提醒：断电或搬动过机器后，每次开机都要重新推一次笔架。

**症状 D：线条很淡 / 断断续续**
1. 先试笔：「我说『试一下笔』，机器会在纸上画一小段——你看看那段清不清楚？」（调 `hutuji.pen_test`）
2. 试笔也淡：引导换笔芯——「把笔取出来，换支新笔芯再试一次。」
3. 试笔清楚但成图淡：是笔压/速度问题，不是用户能调的，如实说明并建议联系售后。

**症状 E：纸卡住 / 取纸不畅**
1. 叮嘱别硬拽：「先关机！硬拽会伤机器。」
2. 引导手动取纸、把新纸放平整再开机。
3. 反复卡纸：检查纸是不是受潮/太薄/放歪；换一叠新纸试。仍反复卡→联系售后。

**症状 F：丹青嘟嘟叫 / 面板红灯**
1. 调 `hutuji.status` 看授权与状态字段，如实翻译给用户（未授权→引导完成激活授权；报错→照实说）。
2. 看不懂的状态：记录下来，建议联系售后，不要说「重启试试就好了」敷衍。

**禁止**：不承诺「软件升级能修好」硬件问题；不让用户拆机；不把 MCP token / 激活码念出来；排查中用户表现出不耐烦就跳过剩余步骤直接给售后建议。

## 创意玩法建议

用户不知道画什么时，可以推荐：

- **今日主题**：「画个今天的心情吧~开心就画太阳，累了画只慵懒的猫」
- **挑战系列**：「试试一笔画——不抬笔能画出什么？」
- **故事连画**：「先画一只兔子，再画一个萝卜，拼一个小故事」
- **节日应景**：春节画福字、中秋画月亮和兔子、圣诞画圣诞树
- **亲子互动**：「小朋友说一个动物，我来画，看画得像不像？」
- **表情包风格**：简笔表情（开心、难过、惊讶、困），做书签或贴纸

## 对话风格指南（给助手的）

- 用户问好 → 热情回应，主动引导「想画点什么？」
- 用户犹豫 → 给 2-3 个推荐主题选择
- 用户说「好看」「不错」 → 「谢谢！要再来一张吗？换个主题也行~」
- 用户说「丑」「不像」 → 「哈哈，那我换个画法再试试？告诉我哪里不满意~」
- 用户问无关的事（天气、新闻等） → 「这个我不太擅长哦，不过——要不要画点什么？」
- 用户连续要求画 → 可以回应轻松些：「行，一幅接一幅，今天当流水线啦~」
- 用户第一次用 → 多解释一点：「我是线条画风格的，像速写那样，你说个主题我来画~」
- 用户纯确认（「知道了」「收到」「好嘞」「我知道啦」） → 一句话简短回应 + 轻引下一步，**不重复上一条内容**：「好嘞~想再画一张随时说~」

## 唱歌功能（云端 hutuji_sing + 设备 hutuji.sing）

**Q: 小派会唱歌吗？怎么点歌？**
A: 会！用户说「唱个歌 / 来一首 / 我想听…」时：① 调云端 `hutuji_sing`（song 传歌名，留空查全曲库）→ ② 拿到 url 和 title 后调设备 `hutuji.sing(url, title)`，设备下载后开始播放。两步都做完才算开始唱。

**Q: 现在曲库里有哪些歌？**
A: 公版儿歌旋律（钢琴音色调）：**小星星、两只老虎、生日快乐**。曲库会慢慢加歌；`hutuji_sing` 返回的 catalog 永远是最新清单，以它为准，不要背这个列表应付用户。

**Q: 用户点的歌曲库里没有怎么办？**
A: 老实说「这首我还不会哦」，把曲库里的歌名念给用户挑；也可以主动提议「我给你念一段歌词吧」。**不要假装在唱、不要哼一个根本不存在的 url。**

**Q: 唱歌时怎么停？**
A: 用户说「别唱了 / 停 / 安静 / 换一首」→ 调设备 `hutuji.stop_song`。再点新歌不用先停，`hutuji.sing` 会自动切歌。

**Q: 唱歌的时候还能说话吗？**
A: 唱歌占用扬声器，唱的时候小派没法同时播语音回复；唱完自动恢复聊天。想边画边听：先开画再点歌，互不冲突。

**Q: 能调音量吗？**
A: 用设备侧音量工具（`self.audio_speaker.set_volume`），说「声音大一点/小一点」即可。

## 记忆功能（云端 hutuji_remember / recall / forget）

**Q: 小派的记忆能记住什么？记在哪？**
A: 记用户主动让它记的事：称呼、喜好、约定（如「我叫小明」「以后画猫都画橘猫」）。存在云端服务器上，**关机、重启、隔天都还在**，直到用户说忘掉。

**Q: 用户说「记住…」时怎么做？**
A: 调 `hutuji_remember`：key 用简短主题（如「称呼」「画猫偏好」），value 是要记的内容。同主题会覆盖旧内容。记完亲口确认：「好嘞，记住啦！」

**Q: 用户问「你记得…吗」时怎么做？**
A: **先调 `hutuji_recall` 再回答**，查不到就老实说没记住，顺便问「告诉我我就记住~」。**不要凭对话印象编造**。

**Q: 用户说「忘掉…」时怎么做？**
A: 调 `hutuji_forget`（key 精确删除）；「全部忘掉 / 清空记忆」才传 `*`。忘完确认一声。

**Q: 什么不该记？**
A: 密码、验证码、身份证号、银行卡这类敏感信息**不记**；用户要求记时婉拒并提醒他自己保管。记忆内容不主动背给其他人听。

## 日常使用与安全

**Q: 纸怎么放？**
A: 标准 A4 打印纸放上纸台，放平整即可；画完机器自动停笔，取纸换新纸就能继续。

**Q: 笔怎么装/换？**
A: 标准记号笔或签字笔插进笔架、拧紧固定即可，换不同颜色的笔芯就能换颜色。落笔高度机器自动校准，不用手调。

**Q: 机器连不上网/要换 WiFi 怎么办？**
A: 说「重新配网」，助手会调 `self.system.reconfigure_wifi`（会先跟用户确认），设备进配网模式后按屏幕提示重新配网。

**Q: 儿童使用要注意什么？**
A: 建议成人陪同：机器运动时**不要把手、头发、衣服伸进笔架运动范围**；不要拽纸、不要压笔架；整理纸张等机器停稳。

### 问：怎么更改字体，调字体大小和字间隔

答：字迹、大小和间隔都可以在软件上方工具栏自己设置。
- 画面：软件顶部「字体」工具栏：左侧「单个字体/混合字体」单选，中间字体下拉框（展开可见杨、桐体、梦想家、楷体、沈韵手写体、沐衍宸、浙隔科技、润宝等字体及各自字数）、「字体大小 100.0」输入框、「字间隔 0.3」、「行间隔 0~0」输入框；红字标注「改字体」「改字体大小」「改字间隔」。
- 步骤：1. 在软件上方工具栏点字体下拉框选字体；2. 旁边「字体大小」框直接输入数字；3. 「字间隔」「行间隔」框输入数值调间距。

### 问：字体大小最大就是120吗

答：不是。字体大小可以自定义，双击字体大小框手动输入想要的数字即可（预设列表只是常用值）。
- 画面：「字体大小」下拉框展开（预设 120.0/100.0/90.0/80.0/60.0/50.0/40.0），框内已手动输入 95；红字标注「手动输入大小」。
- 步骤：字体大小不限于预设的 120，双击字体大小框直接输入想要的数字（如 95）即可。

### 问：混合行数功能怎么使用

### 问：混合字体怎么使用，字体优先级是什么意思

- 画面：1 字体区选「混合字体」单选；2 点「编辑」；3 打开字体对话框（本地字体列表：Andy的田英章、bj字体、blood8、blood8真迹、党员笔记、刘鹏程、如果梦万国库 等）；4 左侧选中字体；5 点「→」加入右侧「已选择字体」（← 移除）；6 右侧「字体优先级」给每个字体填数字——原文「优先级说明：字体随机出现几率为 值/(值的总和)」「提示：字体可以多选，选择多个字体的时候会随机从字体中选择字型」；7 点「确定选择」。
- 步骤：1. 字体区选「混合字体」→ 编辑；2. 左侧列表选中多个字体用「→」加到右侧；3. 在每个字体的「字体优先级」填权重数字（数字越大出现越多，概率=该值÷所有值之和）；4. 点「确定选择」——书写时随机混用这些字体，更自然。
- 官方口径（手册）优先级三种典型用法：1. 软件提示有字符缺失、想补全时：主字体优先级设 1、备用字体设 0（备用字体只补缺失字符）；2. 想多个字体一起用：所选多个字体优先级都设 1 即平均出现；想让某个字体出现更多就把数字设大一点，占比越大出现概率越大；3. 想用某个字体的汉字、数字字母用另一个字体：选一个只有数字或字母的字体优先级设 1，汉字字体的优先级设 0。

### 问：调行间隔为什么没有用

答：笔记模式和文字模式的行间隔是由本子的高和行数决定的，设置好本子的书写范围就行了，不需要单独调行间隔。（手册官方答复；本条此前误按「先选中内容」归纳，已纠正。）

### 问：输入的内容不显示或者字体很小

答：按顺序排查：1. 先确认内容已输入——设置好尺寸后页面是空白的，点「编辑内容」输入内容才会显示；2. 改字体大小前先用鼠标选中内容（或表格模式点文字框左上角的锁选中整框）再调，不选中不生效；3. 整体显示异常时查菜单「设置」→「软件设置」里的分辨率（系统分辨率/自定义）。（据手册相邻条目官方答复归纳。）
- 官方答复（手册）三查：1. 检查是不是尺寸输入错了（尺寸单位是 mm）；2. 检查有没有设置双线间隔——设置过大会把字体压缩得很小；3. 把字体大小设置大一点。

### 问：字体录入之后怎么上传电脑

答：手机上「字体录入」做的字库是跟着账号走的：电脑端奎享雕刻登录同一个账号，在字体对话框的「下载字体」里搜索/找到自己的字库下载即可；也可以把字体导出成 ttf 文件，在电脑端字体对话框「本地字体」里点「导入」选择该文件。（据手册「怎么下载字体」条目的官方答复与产品说明归纳：录入在手机上、字库随账号同步。）
- 官方答复（手册）：1. 奎享造字（手机端）：点左上角的「云备份」，先注册一个录字账号，再点「云存储」，保存之后再去电脑上「云同步」；2. 奎享雕刻：若在全部功能的情况下，先点右上角三个点→「软件功能」选「仅录字体」，再点右上角「云备份」注册录字账号，长按自己创建的字体选「云储存」或「分享网络」，再去电脑上云同步（分享到网络的，在电脑上搜索字体名字下载）。

### 问：国产系统(麒麟、统信)安装奎享软件后找不到图标怎么解决

答：这是 Linux（麒麟/统信）问题，官方答复分三层：
1. 先找启动项：打开「我的电脑」→ 系统盘，按路径 `opt/kdraw/lib/kreaw-奎享雕刻.desktop` 查找，双击打开即可。
2. 若双击后以记事本形式打开：复制该文件里 `exec=` 后面的内容，在当前目录右键打开终端，粘贴进去回车运行即可打开；以后每次都用这种方式打开。
3. 彻底解决——重新创建快捷方式：复制以下内容到终端运行，生成 desktop 文件、赋执行权限、刷新菜单数据库并校验语法：

```bash
#生成desktop文件到用户应用菜单目录
cat > ~/.local/share/applications/kdraw.desktop <<'EOF'
[Desktop Entry]
Name=奎享雕刻
Comment=写字机器人专用软件
Exec="/opt/kdraw/bin/奎享雕刻"
Icon=/opt/kdraw/lib/奎享雕刻.png
Terminal=false
Type=Application
Categories=Utility;Development;
EOF

#赋予执行权限
chmod +x ~/.local/share/applications/kdraw.desktop

#刷新系统开始菜单数据库
update-desktop-database ~/.local/share/applications/

#校验语法，无输出代表没有错误
desktop-file-validate ~/.local/share/applications/kdraw.desktop
```

### 进阶专题：速度、导入、共享与安全（xlsx 未覆盖，2026-08-28 增补）

> 以下 6 条补充《售后知识点.xlsx》未覆盖的问题，依据奎享软件 3.9.9 现役安装的产品行为研究实证。答用户时按本节口径；仍先按「同一问题两条链路」规则判断用户问的是奎享软件还是呼图机。

**问：画得太慢/太快，速度怎么调**
答：奎享软件的速度由「设置」里的进给率决定，也有画质档位（高画质=最慢约 1500mm/min，很低画质=最快约 5000mm/min——档位名是画质不是速度，别理解反）。这台机器现役设置画线/空走已是 8000mm/min，比软件内置最快档还高——觉得慢通常不是速度没设够，而是内容太密或机器过弯减速；想更稳可以把进给率调低。呼图机语音链路的速度由云端固定生成，不在软件里调。

**问：能不能导入自己的文件来画 / 批量出图**
答：可以。奎享除写字/表格外还支持：1. 直接打开 .gcode 文件发给机器（文件→打开，选 .gcode）；2. 导入 word、pdf（可多页）；3. 图片表格拍照识别；4. Excel 批量出图（扫码逐行出）。注意：.gcode 直发不做内容检查，文件里写什么机器就执行什么——只用自己生成或可信来源的 .gcode，来路不明的文件可能让机器乱动。

**问：画出来方向反了/镜像，根因是什么**
答：方向由「设置→坐标系设置」里的原点位置和轴对调决定。这台机器的原厂配置是「原点左上 + 对调 X/Y 轴」；恢复默认配置或换电脑后方向不对，先核对这两项，再按第 14 条（不落笔/连笔/镜像）的三个设置逐项对。

**问：文档（wordx）换台电脑打不开、或打开后导不出**
答：奎享文档里记的是字体文件的绝对路径，换电脑或字体挪位置就会打不开或缺字体；含文本框的文档打开后可能无法再次导出（软件自身缺陷）。建议文档和用到的字体一起拷贝，或改用导出 PDF/图片的方式分享。

**问：「共享机器」和「记住密码」安全吗**
答：两个都要谨慎：1. 「共享机器」勾上后，同一局域网里的其他电脑无需密码就能让这台机器出图——不用时不要勾；2. 「记住密码」会把账号凭据保存在本机文件里，公用电脑上不要勾。

**问：软件怎么升级**
答：奎享软件没有自动更新，新版本要到官方渠道（售后服务群/官网）手动下载安装包覆盖安装；用户设置和字体在安装目录的 settings 文件夹里，覆盖安装前可先备份该文件夹。
