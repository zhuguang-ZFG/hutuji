# 呼图机知识库（上传到小智「我的知识库」）

文档用途：供智能体检索，回答「能画什么、怎么画、不能做什么、工具怎么用」。

## 产品是什么

**呼图机**（hutuji）是一台 **AI 智能绘图机**：对它说话，它就帮你画出来——语音指令 → 云端 AI 生成绘图 → 写字机自动落笔，画完自动换纸，可以连续出作品。

它有两颗芯片协同工作：一颗负责听你说话和理解意图（ESP32-S3 小派），另一颗负责精确控制画笔运动和换纸（ESP32 Grbl）。两颗芯片通过 WiFi 通讯。

## 能画什么

呼图机擅长 **线条艺术**——用一支笔描绘轮廓和线条，风格类似速写、简笔画、线描插画。

### 特别适合画的

- **动物**：小猫、小狗、小鸟、兔子、鱼、蝴蝶等简笔轮廓
- **植物**：花朵、树木、叶子、仙人掌、向日葵的线描
- **日常物品**：自行车、杯子、房子、汽车、灯泡、雨伞
- **人物剪影**：侧脸轮廓、人物站姿/坐姿剪影
- **场景小品**：树枝上的鸟、窗边的花瓶、月亮和星星
- **文字书法**：汉字、英文字母（单线书法风格；「福」字这类大字实测效果稳定）
- **几何图案**：星星、心形、雪花、简单曼陀罗

### 画不了的

- 照片级写实（没有阴影渐变）
- 填色/涂色（只有线条）
- 油画/水彩效果
- 大面积色块
- 精细像素画

遇到画不了的需求时，建议用户换成线条风格的替代方案。

## 出图前准备（笔架归位）

- **每次开机、断电重启或搬动过机器后，第一次出图前**：用手把笔架往**左下角**推、推到底（推到机械死点）。机器没有限位感应，靠这一下确定画图原点；不推的话画面会偏。
- 推一次就够：之后连续出图、自动换纸都不用重复推。
- 抬笔落笔（Z 方向）机器会自动校准，用户不用管。

## 用户怎么说效果好

### 好的说法（推荐）

- 「画一只小猫」→ AI 自动补全为合适的线描风格
- 「画朵向日葵」
- 「画个自行车」
- 「画一只站在树枝上的小鸟」
- 「写个大大的福字」
- 「画个简笔画的小房子，旁边有棵树」
- 「画一条鱼，侧面的」

### 不太好的说法

- 「画得像照片一样真实」→ 建议改成线描风格
- 一次要求画整个故事 → 建议拆成一幅一幅来
- 含大量参数/色值 → 提醒只有黑白线条

### AI 怎么补全

用户说的往往很简短，AI 应补全成适合线描绘图的描述：
- 「画个猫」→ description：`单线简笔小猫，侧面站姿，留白构图`
- 「来朵花」→ description：`一朵盛开的花朵线描，花瓣舒展`
- 「画条鱼」→ description：`单线简笔小鱼，侧面游动姿态`

## 工具清单（云端 MCP）

### hutuji_draw

- **何时用**：用户要画图、出作品时。  
- **参数 description**：简短中文绘画主题（建议带「单线」「简笔」「线描」）。  
- **结果**：返回 G-code 下载 URL；设备再下载执行。  
- **注意（两步衔接）**：本工具只生成图并返回下载 `url`，**不会**让写字机动；拿到 `url` 后须再调设备侧 `hutuji.draw`(url) 才会真正落笔（不存在「自动衔接」，漏调则纸不动）。一次只发起一幅，上一幅未完成不要连续触发。

### hutuji_status

- **何时用**：用户问云端生成服务是否正常。  
- **不要**用它代替设备实时状态查询（那是设备侧 `hutuji.status`）。

### hutuji_preview_svg

- **何时用**：只看矢量草稿效果、不要马上出纸。  
- 调试用，不触发写字机运动。

## 工具清单（设备侧，S3）

### hutuji.status

查询设备与写字机的连接状态：是否连通、Grbl 是否就绪、是否已授权、当前任务状态。

### hutuji.draw

参数 `url`：下载该 url 的 G-code 并逐行转发给写字机。**这一步才是真正出图**——云端 `hutuji_draw` 只生成 url，须由助手把 url 传入本工具；漏调则纸不动。

### hutuji.abort

尝试中止当前任务。换纸动作一旦开始，物理上可能无法立刻停，需如实告知用户。

### hutuji.pause / hutuji.resume

- **暂停**：用户说「暂停」「等一下」「先停一下」时调用 `hutuji.pause`。笔会停在原地，进度不丢。
- **继续**：用户说「继续」「接着画」时调用 `hutuji.resume`，从暂停处接着画。
- **区别**：不要把「暂停」误用成 `hutuji.abort`；abort 会放弃当前任务，pause 可以继续。
- 换纸过程中不能暂停，应如实说明要等换纸结束。
- **暂停有时限**：暂停超过约 10 分钟，设备会自动取消这一幅（抬笔、任务结束）；之后再说「继续」已无法接续，需重新画。

### hutuji.repeat

用户说「再画一张」「一样的再来一次」时调用。设备复用上一张的 G-code，不重新生成。画完会自动换纸，用户不需要手动换纸；如果还没有成功画过上一张，工具会返回错误。

### hutuji.pen_test

用户怀疑笔没墨、没有触纸或要求试笔时调用。机器会落笔停 1 秒再抬笔；随后提醒用户检查纸上是否留下点迹。

## 常见问题

**Q：为什么画出来都是线条？**  
A：呼图机是线描绘图机，用一支笔勾勒轮廓，这就是它的风格特色——像速写和简笔画。

**Q：能不能画彩色的？**  
A：目前只支持单色线条。可以换不同颜色的笔芯，但同一幅画只有一种颜色。

**Q：我说了画，它怎么没动？**  
A：可能是：①云端 `hutuji_draw` 生成成功后漏调了设备 `hutuji.draw(url)`；②云端服务还没准备好（查 `hutuji_status`）；③设备没连上写字机（查 `hutuji.status`）；④缺纸了；⑤写字机未授权。

**Q：画太复杂会怎样？**  
A：云端有内容校验，太复杂可能失败。建议换个更简洁的描述再试。

**Q：正在画能不能停？**  
A：可以说「停下」。如果正在换纸，机器无法立即停，会在当前换纸完成后停止任务。

**Q：它能连续画很多张吗？**  
A：可以！画完一张自动换纸，说下一个主题就继续画。

**Q：画的大小怎么控制？**  
A：云端按固定可画区域生成，用户通常无需指定尺寸；如果要求超出范围，会拒绝整幅生成并说明原因，不会裁剪或静默缩放。

**Q：说完要等多久才开始画？**  
A：云端 AI 生成图稿需要时间，**通常 10~40 秒**（主题复杂会更久）。生成好后写字机才开始落笔。等的时候不用重复说，重复说会重新排队。

**Q：同一个主题画两次，会一模一样吗？**  
A：不会。AI 每次创作都有变化，同样的话两次画出来的构图会不同。想要一模一样的一张，说「再画一张」（复用上一张的图稿）；想要同主题换个画法，说「换个姿势/换个构图」。

**Q：画面在纸上的位置和大小能指定吗？**  
A：不用指定。云端会自动把主体**居中并留好边距**（四周约 10mm），太小会放大、太大会收小，但不会超出可画区。

**Q：为什么提示「太复杂」或生成失败？**  
A：两种情况：①主题细节太多，超过单线稿能表达的上限，云端会拒绝并说明，换个更简洁的描述即可；②生图服务临时繁忙，等一两分钟再试就好。

## 语音识别纠错（听不准时据此猜回意图）

语音转文字常把同音/近音字认错。遇到下表左列或类似怪词时，按右列理解意图，必要时反问一句确认：

| 语音可能被识别成 | 真实意图 |
|---|---|
| 花一只猫 / 划一只猫 / 话一只猫 | 画一只猫 |
| 画朵火 / 话朵花 / 滑朵花 | 画一朵花 |
| 在来一张 / 再来一涨 | 再来一张（重画/换主题） |
| 听下 / 挺下 / 停一下下 | 停下 / 暂停 |
| 接着话 / 继续话 | 继续画 |
| 画个福子 / 画个胡子（语境为写字时） | 写/画个「福」字 |

兜底原则：上表只是高频示例，没列到的怪词同样先按最接近的绘图意图猜，猜不准就反问「你是想画___吗？」，不要直接画错或报错。

## 硬件规格

**纸张**：标准 A4 打印纸（210×297mm），横向放置。可画区域约 **190×277mm**（X≤190、Y≤277），四周留约 10mm 边距；任一坐标越界时云端会拒绝整幅生成并说明原因，不会裁剪或静默缩放，所以构图别顶到纸边。

**画笔**：标准记号笔/签字笔，笔芯可更换。默认黑色，换不同颜色笔芯可画其他颜色，但同一幅画只有一种颜色。

**速度**：一幅简笔画大约 1-3 分钟，复杂线描可能 5-8 分钟。速度由写字机运动控制决定，软件无法调快。

**换纸**：画完自动换纸，通常需要 60 秒以上；系统按 90 秒换纸应答上限等待。换纸过程中无法立即停止；收到停止请求后会等当前换纸完成再结束任务。

**精度**：笔触精度约 0.1mm，足以表现细节丰富的线描。

## 故障排查

**Q：说了画但没反应**  
A：依次排查——① 云端：调 `hutuji_status` 看 MCP 服务是否正常；② 设备端：调 `hutuji.status` 看写字机是否在线；③ WiFi：检查写字机网络连接；④ 纸张：可能缺纸了；⑤ 授权：写字机可能未授权。

**Q：画到一半停了**  
A：可能是 WiFi 断连。写字机**不会从断点续画**——网络恢复后它会用缓存从这一幅的开头重画（已画过的部分会重走一遍）。如果长时间不动，调 `hutuji.status` 查看状态。

**Q：画的线条很粗/很淡**  
A：这和笔芯有关，不是软件能控制的。换支好笔或新笔芯就行。

**Q：纸卡住了**  
A：别硬拽！关电源，手动取出纸张，重新放好纸再开机。

**Q：写字机一直嘟嘟叫**  
A：可能在等授权或者报错了。看看面板灯的状态，或者调 `hutuji.status` 问问。

**Q：画偏了 / 画到纸外面去了**  
A：几乎都是笔架没归位。这台机器没有限位感应，开机后要先手动把笔架推到**左下角推到底**来定原点（见「出图前准备」）。断电或搬动过机器后都要重新推一次。

**Q：画出来的和我想的不一样**  
A：这是 AI 理解偏差，不是故障。把描述说得更具体一点（品种、姿势、朝向、要不要配角），或者说「换个构图」让它重来一版。

**Q：提示生成失败 / 服务繁忙**  
A：云端生图服务临时拥挤，稍等一两分钟重新说一遍即可；连续多次失败就调 `hutuji_status` 看服务状态并如实告知。

## 创意玩法建议

用户不知道画什么时，可以推荐：

- **今日主题**：「画个今天的心情吧~开心就画太阳，累了画只慵懒的猫」
- **挑战系列**：「试试一笔画——不抬笔能画出什么？」
- **故事连画**：「先画一只兔子，再画一个萝卜，拼一个小故事」
- **节日应景**：春节画福字、中秋画月亮和兔子、圣诞画圣诞树
- **亲子互动**：「小朋友说一个动物，我来画，看画得像不像？」
- **表情包风格**：简笔表情（开心、难过、惊讶、困），做书签或贴纸

## 对话风格指南（给助手的）

- 用户问好 → 热情回应，主动引导「想画点什么？」
- 用户犹豫 → 给 2-3 个推荐主题选择
- 用户说「好看」「不错」 → 「谢谢！要再来一张吗？换个主题也行~」
- 用户说「丑」「不像」 → 「哈哈，那我换个画法再试试？告诉我哪里不满意~」
- 用户问无关的事（天气、新闻等） → 「这个我不太擅长哦，不过——要不要画点什么？」
- 用户连续要求画 → 可以回应轻松些：「行，一幅接一幅，今天当流水线啦~」
- 用户第一次用 → 多解释一点：「我是线条画风格的，像速写那样，你说个主题我来画~」

## 禁止事项（助手必须遵守）

- 不向用户泄露 MCP token、API key、服务器密码。  
- 不声称能合并双芯片固件或改用 USB Host（已否决）。

## 唱歌功能（云端 hutuji_sing + 设备 hutuji.sing）

**Q: 小派会唱歌吗？怎么点歌？**
A: 会！用户说「唱个歌 / 来一首 / 我想听…」时：① 调云端 `hutuji_sing`（song 传歌名，留空查全曲库）→ ② 拿到 url 和 title 后调设备 `hutuji.sing(url, title)`，设备下载后开始播放。两步都做完才算开始唱。

**Q: 现在曲库里有哪些歌？**
A: 公版儿歌旋律（钢琴音色调）：**小星星、两只老虎、生日快乐**。曲库会慢慢加歌；`hutuji_sing` 返回的 catalog 永远是最新清单，以它为准，不要背这个列表应付用户。

**Q: 用户点的歌曲库里没有怎么办？**
A: 老实说「这首我还不会哦」，把曲库里的歌名念给用户挑；也可以主动提议「我给你念一段歌词吧」。**不要假装在唱、不要哼一个根本不存在的 url。**

**Q: 唱歌时怎么停？**
A: 用户说「别唱了 / 停 / 安静 / 换一首」→ 调设备 `hutuji.stop_song`。再点新歌不用先停，`hutuji.sing` 会自动切歌。

**Q: 唱歌的时候还能说话吗？**
A: 唱歌占用扬声器，唱的时候小派没法同时播语音回复；唱完自动恢复聊天。想边画边听：先开画再点歌，互不冲突。

**Q: 能调音量吗？**
A: 用设备侧音量工具（`self.audio_speaker.set_volume`），说「声音大一点/小一点」即可。

## 记忆功能（云端 hutuji_remember / recall / forget）

**Q: 小派的记忆能记住什么？记在哪？**
A: 记用户主动让它记的事：称呼、喜好、约定（如「我叫小明」「以后画猫都画橘猫」）。存在云端服务器上，**关机、重启、隔天都还在**，直到用户说忘掉。

**Q: 用户说「记住…」时怎么做？**
A: 调 `hutuji_remember`：key 用简短主题（如「称呼」「画猫偏好」），value 是要记的内容。同主题会覆盖旧内容。记完亲口确认：「好嘞，记住啦！」

**Q: 用户问「你记得…吗」时怎么做？**
A: **先调 `hutuji_recall` 再回答**，查不到就老实说没记住，顺便问「告诉我我就记住~」。**不要凭对话印象编造**。

**Q: 用户说「忘掉…」时怎么做？**
A: 调 `hutuji_forget`（key 精确删除）；「全部忘掉 / 清空记忆」才传 `*`。忘完确认一声。

**Q: 什么不该记？**
A: 密码、验证码、身份证号、银行卡这类敏感信息**不记**；用户要求记时婉拒并提醒他自己保管。记忆内容不主动背给其他人听。

## 日常使用与安全

**Q: 纸怎么放？**
A: 标准 A4 打印纸横向放上纸台，放平整即可；画完机器自动换纸，一叠纸能连续画很多张。

**Q: 笔怎么装/换？**
A: 标准记号笔或签字笔插进笔架、拧紧固定即可，换不同颜色的笔芯就能换颜色。落笔高度机器自动校准，不用手调。

**Q: 机器连不上网/要换 WiFi 怎么办？**
A: 说「重新配网」，助手会调 `self.system.reconfigure_wifi`（会先跟用户确认），设备进配网模式后按屏幕提示重新配网。

**Q: 儿童使用要注意什么？**
A: 建议成人陪同：机器运动时**不要把手、头发、衣服伸进笔架运动范围**；不要拽纸、不要压笔架；换纸等机器停稳再整理纸张。

### 问：软件打不开、启动报错怎么办（VC++ Runtime Error / Couldn't load main class / Self-protection failed / No JVM）

答：通用处理：1. 把软件安装目录加入杀毒软件白名单后用官方安装包重装；2. 右键「以管理员身份运行」；3. 双击软件安装目录里下载的「启动奎享雕刻」程序打开；4. 报 No JVM 时安装 32 位 JRE。
- 画面：「Microsoft Visual C++ Runtime Library」错误弹窗，原文：「Runtime Error! Program: D:\KX\??.exe  abnormal program termination」，下方「确定」。
- 内容：奎享软件启动/运行中崩溃报 VC++ 运行库错误。处理方向：重装/修复微软 Visual C++ 运行库，或重装奎享软件到全英文路径（路径含中文/特殊字符时 ?? 处会乱码）。
- 画面：「Error」弹窗，原文：「Couldn't load main class.」下方「确定」。
- 内容：软件主程序加载失败（Java 主类找不到）。处理方向：安装包损坏或被杀毒软件误删组件——重新下载安装包、关闭杀毒软件后重装；仍不行用安装目录里的「启动奎享雕刻」程序打开（见序号43 文字答案）。
- 画面：「Error」弹窗，原文：「Self-protection failed. Error code: 4」，下方「确定」。
- 内容：软件自保护校验失败（常见于文件被杀毒软件改动/误删或权限不足）。处理：把软件目录加入杀毒软件白名单后重装；右键「以管理员身份运行」；仍不行用安装目录的「启动奎享雕刻」打开。
- 画面：「Error」弹窗，原文：「No JVM could be found on your system. Please define EXE4J_JAVA_HOME to point to an installed 32-bit JDK or JRE or download a JRE from www.java.com.」；背景桌面可见「奎享字体」「奎享雕刻」图标。
- 内容：系统缺 Java 运行环境（32 位 JRE）导致软件无法启动。处理：1. 重装奎享官方完整安装包（自带运行环境）；2. 或按提示安装 32 位 JRE 并设置 EXE4J_JAVA_HOME；3. 也可以直接双击软件安装目录里下载的「启动奎享雕刻」打开（序号43 文字答案同此）。

### 问：机器书写不写字、只画斜线、字写斜了怎么调

- 画面：纸张实拍：一行手写字斜向压在表格框线附近，笔画歪斜不成行——即「机器书写不写字/只画斜线」的故障现象。
- 内容：出现整行斜写/只画斜线时，多为机器坐标系/机型配置不对——按「工具→机器配置」选「派曦科技写字机专用」（image56），再在「设置→坐标系设置」核对反转/对调与起点位置（image3/57），重置后重试。
- 画面：菜单「工具」→「机器配置」对话框：「请选择机器：请选择和你机器型号对应的配置」，下拉展开：KX-02 / KX-03 / KX-04 / KX-05 / 派曦科技写字机专用 / 金十科技写字机专用。红字原文：「在工具里面选择下载默认配置 选择派曦科技写字机专用就行」。
- 步骤：1. 菜单「工具」→「机器配置」；2. 下拉选「派曦科技写字机专用」（按实际机型，KX 系列选对应型号）；3. 保存——机器行为异常/参数不对时先恢复这套默认配置。
- 画面：1 菜单「设置」→ 2「坐标系设置」对话框：3 坐标轴勾选区「反转X轴」「反转Y轴」「对调X轴和Y轴」（图中勾对调）、起点位置「左上(LeftUp)」、「表格坐标系锁定位置」□；4 底部「保存」「重置」；5 左侧「更新」。
- 步骤（写字方向不对/镜像的另一处确认点）：1. 「设置」→「坐标系设置」；2. 按需勾反转/对调；3. 点「保存」（不是只关窗）；4. 左侧点「更新」；仍不对点「重置」恢复。

### 问：调行间隔为什么没有用

答：和「改字体大小没变化」是同一类原因——必须先用鼠标选中（拖蓝）要调整的内容，再去上方工具栏调「行间隔」，不选中直接改不生效；如果界面还没显示内容，先点「编辑内容」输入内容后再调。（据手册相邻条目「为什么更改字体和大小没有变化呢」「为什么设置好尺寸之后软件界面不显示横线」的官方答复归纳，根因相同。）

### 问：输入的内容不显示或者字体很小

答：按顺序排查：1. 先确认内容已输入——设置好尺寸后页面是空白的，点「编辑内容」输入内容才会显示；2. 改字体大小前先用鼠标选中内容（或表格模式点文字框左上角的锁选中整框）再调，不选中不生效；3. 整体显示异常时查菜单「设置」→「软件设置」里的分辨率（系统分辨率/自定义）。（据手册相邻条目官方答复归纳。）

### 问：字体录入之后怎么上传电脑

答：手机上「字体录入」做的字库是跟着账号走的：电脑端奎享雕刻登录同一个账号，在字体对话框的「下载字体」里搜索/找到自己的字库下载即可；也可以把字体导出成 ttf 文件，在电脑端字体对话框「本地字体」里点「导入」选择该文件。（据手册「怎么下载字体」条目的官方答复与产品说明归纳：录入在手机上、字库随账号同步。）

### 问：国产系统(麒麟、统信)安装奎享软件后找不到图标怎么解决

答：安装后桌面没有图标时，直接打开软件的安装目录，双击目录里下载的「启动奎享雕刻」程序即可打开软件（与手册「软件打不开」条目的官方答复相同）；以后可以从安装目录把该程序发送到桌面快捷方式。
