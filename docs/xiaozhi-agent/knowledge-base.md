# 呼图机知识库（上传到小智「我的知识库」）

文档用途：供智能体检索，回答「能画什么、怎么画、不能做什么、工具怎么用」。

## 产品是什么

**呼图机**（hutuji）是一台 **AI 智能绘图机**：对它说话，它就帮你画出来——语音指令 → 云端 AI 生成绘图 → 写字机自动落笔，画完自动换纸，可以连续出作品。

它有两颗芯片协同工作：一颗负责听你说话和理解意图（ESP32-S3 小派），另一颗负责精确控制画笔运动和换纸（ESP32 Grbl）。两颗芯片通过 WiFi 通讯。

## 能画什么

呼图机擅长 **线条艺术**——用一支笔描绘轮廓和线条，风格类似速写、简笔画、线描插画。

### 特别适合画的

- **动物**：小猫、小狗、小鸟、兔子、鱼、蝴蝶等简笔轮廓
- **植物**：花朵、树木、叶子、仙人掌、向日葵的线描
- **日常物品**：自行车、杯子、房子、汽车、灯泡、雨伞
- **人物剪影**：侧脸轮廓、人物站姿/坐姿剪影
- **场景小品**：树枝上的鸟、窗边的花瓶、月亮和星星
- **文字书法**：汉字、英文字母（单线书法风格；「福」字这类大字实测效果稳定）
- **几何图案**：星星、心形、雪花、简单曼陀罗

### 画不了的

- 照片级写实（没有阴影渐变）
- 填色/涂色（只有线条）
- 油画/水彩效果
- 大面积色块
- 精细像素画

遇到画不了的需求时，建议用户换成线条风格的替代方案。

## 出图前准备（笔架归位）

- **每次开机、断电重启或搬动过机器后，第一次出图前**：用手把笔架往**左下角**推、推到底（推到机械死点）。机器没有限位感应，靠这一下确定画图原点；不推的话画面会偏。
- 推一次就够：之后连续出图、自动换纸都不用重复推。
- 抬笔落笔（Z 方向）机器会自动校准，用户不用管。

## 用户怎么说效果好

### 好的说法（推荐）

- 「画一只小猫」→ AI 自动补全为合适的线描风格
- 「画朵向日葵」
- 「画个自行车」
- 「画一只站在树枝上的小鸟」
- 「写个大大的福字」
- 「画个简笔画的小房子，旁边有棵树」
- 「画一条鱼，侧面的」

### 不太好的说法

- 「画得像照片一样真实」→ 建议改成线描风格
- 一次要求画整个故事 → 建议拆成一幅一幅来
- 含大量参数/色值 → 提醒只有黑白线条

### AI 怎么补全

用户说的往往很简短，AI 应补全成适合线描绘图的描述：
- 「画个猫」→ description：`单线简笔小猫，侧面站姿，留白构图`
- 「来朵花」→ description：`一朵盛开的花朵线描，花瓣舒展`
- 「画条鱼」→ description：`单线简笔小鱼，侧面游动姿态`

## 工具清单（云端 MCP）

### hutuji_draw

- **何时用**：用户要画图、出作品时。  
- **参数 description**：简短中文绘画主题（建议带「单线」「简笔」「线描」）。  
- **结果**：返回 G-code 下载 URL；设备再下载执行。  
- **注意（两步衔接）**：本工具只生成图并返回下载 `url`，**不会**让写字机动；拿到 `url` 后须再调设备侧 `hutuji.draw`(url) 才会真正落笔（不存在「自动衔接」，漏调则纸不动）。一次只发起一幅，上一幅未完成不要连续触发。

### hutuji_status

- **何时用**：用户问云端生成服务是否正常。  
- **不要**用它代替设备实时状态查询（那是设备侧 `hutuji.status`）。

### hutuji_preview_svg

- **何时用**：只看矢量草稿效果、不要马上出纸。  
- 调试用，不触发写字机运动。

## 工具清单（设备侧，S3）

### hutuji.status

查询设备与写字机的连接状态：是否连通、Grbl 是否就绪、是否已授权、当前任务状态。

### hutuji.draw

参数 `url`：下载该 url 的 G-code 并逐行转发给写字机。**这一步才是真正出图**——云端 `hutuji_draw` 只生成 url，须由助手把 url 传入本工具；漏调则纸不动。

### hutuji.abort

尝试中止当前任务。换纸动作一旦开始，物理上可能无法立刻停，需如实告知用户。

### hutuji.pause / hutuji.resume

- **暂停**：用户说「暂停」「等一下」「先停一下」时调用 `hutuji.pause`。笔会停在原地，进度不丢。
- **继续**：用户说「继续」「接着画」时调用 `hutuji.resume`，从暂停处接着画。
- **区别**：不要把「暂停」误用成 `hutuji.abort`；abort 会放弃当前任务，pause 可以继续。
- 换纸过程中不能暂停，应如实说明要等换纸结束。
- **暂停有时限**：暂停超过约 10 分钟，设备会自动取消这一幅（抬笔、任务结束）；之后再说「继续」已无法接续，需重新画。

### hutuji.repeat

用户说「再画一张」「一样的再来一次」时调用。设备复用上一张的 G-code，不重新生成。画完会自动换纸，用户不需要手动换纸；如果还没有成功画过上一张，工具会返回错误。

### hutuji.pen_test

用户怀疑笔没墨、没有触纸或要求试笔时调用。机器会落笔停 1 秒再抬笔；随后提醒用户检查纸上是否留下点迹。

## 常见问题

**Q：为什么画出来都是线条？**  
A：呼图机是线描绘图机，用一支笔勾勒轮廓，这就是它的风格特色——像速写和简笔画。

**Q：能不能画彩色的？**  
A：目前只支持单色线条。可以换不同颜色的笔芯，但同一幅画只有一种颜色。

**Q：我说了画，它怎么没动？**  
A：可能是：①云端 `hutuji_draw` 生成成功后漏调了设备 `hutuji.draw(url)`；②云端服务还没准备好（查 `hutuji_status`）；③设备没连上写字机（查 `hutuji.status`）；④缺纸了；⑤写字机未授权。

**Q：画太复杂会怎样？**  
A：云端有内容校验，太复杂可能失败。建议换个更简洁的描述再试。

**Q：正在画能不能停？**  
A：可以说「停下」。如果正在换纸，机器无法立即停，会在当前换纸完成后停止任务。

**Q：它能连续画很多张吗？**  
A：可以！画完一张自动换纸，说下一个主题就继续画。

**Q：画的大小怎么控制？**  
A：云端按固定可画区域生成，用户通常无需指定尺寸；如果要求超出范围，会拒绝整幅生成并说明原因，不会裁剪或静默缩放。

**Q：说完要等多久才开始画？**  
A：云端 AI 生成图稿需要时间，**通常 10~40 秒**（主题复杂会更久）。生成好后写字机才开始落笔。等的时候不用重复说，重复说会重新排队。

**Q：同一个主题画两次，会一模一样吗？**  
A：不会。AI 每次创作都有变化，同样的话两次画出来的构图会不同。想要一模一样的一张，说「再画一张」（复用上一张的图稿）；想要同主题换个画法，说「换个姿势/换个构图」。

**Q：画面在纸上的位置和大小能指定吗？**  
A：不用指定。云端会自动把主体**居中并留好边距**（四周约 10mm），太小会放大、太大会收小，但不会超出可画区。

**Q：为什么提示「太复杂」或生成失败？**  
A：两种情况：①主题细节太多，超过单线稿能表达的上限，云端会拒绝并说明，换个更简洁的描述即可；②生图服务临时繁忙，等一两分钟再试就好。

## 语音识别纠错（听不准时据此猜回意图）

语音转文字常把同音/近音字认错。遇到下表左列或类似怪词时，按右列理解意图，必要时反问一句确认：

| 语音可能被识别成 | 真实意图 |
|---|---|
| 花一只猫 / 划一只猫 / 话一只猫 | 画一只猫 |
| 画朵火 / 话朵花 / 滑朵花 | 画一朵花 |
| 在来一张 / 再来一涨 | 再来一张（重画/换主题） |
| 听下 / 挺下 / 停一下下 | 停下 / 暂停 |
| 接着话 / 继续话 | 继续画 |
| 画个福子 / 画个胡子（语境为写字时） | 写/画个「福」字 |

兜底原则：上表只是高频示例，没列到的怪词同样先按最接近的绘图意图猜，猜不准就反问「你是想画___吗？」，不要直接画错或报错。

## 硬件规格

**纸张**：标准 A4 打印纸（210×297mm），横向放置。可画区域约 **190×277mm**（X≤190、Y≤277），四周留约 10mm 边距；任一坐标越界时云端会拒绝整幅生成并说明原因，不会裁剪或静默缩放，所以构图别顶到纸边。

**画笔**：标准记号笔/签字笔，笔芯可更换。默认黑色，换不同颜色笔芯可画其他颜色，但同一幅画只有一种颜色。

**速度**：一幅简笔画大约 1-3 分钟，复杂线描可能 5-8 分钟。速度由写字机运动控制决定，软件无法调快。

**换纸**：画完自动换纸，通常需要 60 秒以上；系统按 90 秒换纸应答上限等待。换纸过程中无法立即停止；收到停止请求后会等当前换纸完成再结束任务。

**精度**：笔触精度约 0.1mm，足以表现细节丰富的线描。

## 故障排查

**Q：说了画但没反应**  
A：依次排查——① 云端：调 `hutuji_status` 看 MCP 服务是否正常；② 设备端：调 `hutuji.status` 看写字机是否在线；③ WiFi：检查写字机网络连接；④ 纸张：可能缺纸了；⑤ 授权：写字机可能未授权。

**Q：画到一半停了**  
A：可能是 WiFi 断连。写字机**不会从断点续画**——网络恢复后它会用缓存从这一幅的开头重画（已画过的部分会重走一遍）。如果长时间不动，调 `hutuji.status` 查看状态。

**Q：画的线条很粗/很淡**  
A：这和笔芯有关，不是软件能控制的。换支好笔或新笔芯就行。

**Q：纸卡住了**  
A：别硬拽！关电源，手动取出纸张，重新放好纸再开机。

**Q：写字机一直嘟嘟叫**  
A：可能在等授权或者报错了。看看面板灯的状态，或者调 `hutuji.status` 问问。

**Q：画偏了 / 画到纸外面去了**  
A：几乎都是笔架没归位。这台机器没有限位感应，开机后要先手动把笔架推到**左下角推到底**来定原点（见「出图前准备」）。断电或搬动过机器后都要重新推一次。

**Q：画出来的和我想的不一样**  
A：这是 AI 理解偏差，不是故障。把描述说得更具体一点（品种、姿势、朝向、要不要配角），或者说「换个构图」让它重来一版。

**Q：提示生成失败 / 服务繁忙**  
A：云端生图服务临时拥挤，稍等一两分钟重新说一遍即可；连续多次失败就调 `hutuji_status` 看服务状态并如实告知。

## 创意玩法建议

用户不知道画什么时，可以推荐：

- **今日主题**：「画个今天的心情吧~开心就画太阳，累了画只慵懒的猫」
- **挑战系列**：「试试一笔画——不抬笔能画出什么？」
- **故事连画**：「先画一只兔子，再画一个萝卜，拼一个小故事」
- **节日应景**：春节画福字、中秋画月亮和兔子、圣诞画圣诞树
- **亲子互动**：「小朋友说一个动物，我来画，看画得像不像？」
- **表情包风格**：简笔表情（开心、难过、惊讶、困），做书签或贴纸

## 对话风格指南（给助手的）

- 用户问好 → 热情回应，主动引导「想画点什么？」
- 用户犹豫 → 给 2-3 个推荐主题选择
- 用户说「好看」「不错」 → 「谢谢！要再来一张吗？换个主题也行~」
- 用户说「丑」「不像」 → 「哈哈，那我换个画法再试试？告诉我哪里不满意~」
- 用户问无关的事（天气、新闻等） → 「这个我不太擅长哦，不过——要不要画点什么？」
- 用户连续要求画 → 可以回应轻松些：「行，一幅接一幅，今天当流水线啦~」
- 用户第一次用 → 多解释一点：「我是线条画风格的，像速写那样，你说个主题我来画~」

### 冲突口径已纠正（必须按呼图机口径回答）

- **怎么连接机器，可以网络连接吗**：旧资料说「用数据线连电脑，端口选 com1 以外的再点连接；不支持网络连接」。**呼图机正相反——必须联网**：设备连上 WiFi，你对小派说话，小派云端 AI 生成绘图指令，设备下载校验后转给写字机落笔。没网就画不了，也不需要电脑连线。
- **怎么用蓝牙连接**：旧资料教手机/电脑蓝牙配对「paixi」或「btwrite」再在软件里连。**呼图机不用蓝牙配对，也不需要手机或电脑软件**——出图数据只走 WiFi，直接说话就行。

### 呼图机同样适用（问的是写字机本体）

> 这几条问的是机器本体，呼图机同样会遇到，但**处理方式按呼图机的说**。

- **可以共享写字机吗**：一次只画一幅，大家排队来——这幅画完就轮到下一位。
- **机器报警了 / 提示异常警告怎么弄**：关键一条与旧资料一致——**别去点机器上的「机器原点」「设置原点」「复位」**。呼图机没有限位感应，回原点动作可能让笔架撞到底。正确做法：调 `hutuji.status` 看状态，按「画偏了」那条手动把笔架推到左下角定原点；反复报警就断电等几分钟再开机。
- **不落笔 / 只画斜线 / 连笔**：先调 `hutuji.pen_test` 试笔——纸上没点迹就是笔的问题，换支笔或新笔芯。试笔有点迹却画成斜线连笔，是机器的落笔高度和方向参数不对；**呼图机的落笔抬笔高度由云端固定生成，方向是出厂设置，用户不要自己改**，请联系售后，不要照旧资料去逐项试固件参数。
- **机器写着突然不动了**：旧资料归因于杀毒软件和数据线，呼图机没有这两样。呼图机多半是 WiFi 断连，见上文「画到一半停了」。
- **能不能画完不回起点**：不能。呼图机画完必须回原点才能自动换纸，这是固定流程，没有开关。

### 奎享软件专属（呼图机没有对应功能）

> 用户问到下面这些，都是奎享写字软件的用法。呼图机没有软件界面、没有字体和表格设置，统一这样回：「这些是奎享写字软件里的设置，呼图机不用装软件——你直接告诉我想画什么就行。」**不要**照奎享的步骤回答。

- **字体与排版**：改字体/字号/字间隔、字体大小上限、行间隔、混合行数、混合字体与优先级、下载字体、字体录入后上传电脑、内容格式（首行居中/缩进）、首行超出范围、标点间隔、贴线书写、首字随机缩进、字体浮动与变形、改了字体没变化、内容不显示或字体很小、界面不显示横线。
- **本子与表格**：文字模式本子参数、表格模板打开使用、表格模式批量改字体、单元格变红提示显示不完整、工程表格串行写不对格、表格与签名一起写、图文一起书写、图片表格拍照识别、多页文字、多色书写。
- **导入与打印**：导入 word 文档、pdf 一次导入多页。
- **软件连接与开关**：连接失败/端口被占用、软件右侧没有连接和书写、关掉书写完成提示音。
- **软件安装报错**：no jvm could be found、Couldn't load main class、Runtime Error 路径显示问号、Self-protection failed（Error code: 4）、国产系统（麒麟/统信）装完找不到图标。
