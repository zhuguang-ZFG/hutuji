# hutuji 写字机知识库（上传到小智「我的知识库」）

文档用途：供智能体检索，回答「能画什么、怎么画、不能做什么、工具怎么用」。

## 产品是什么

hutuji 是一台 **AI 绘图自动换纸写字机**：语音指令 → 云端生成单线笔画 → 写字机落笔并自动换纸。  
架构是双芯片：ESP32-S3（小智语音）+ 独立 ESP32（Grbl 运动/换纸）。板间用 WiFi Telnet，不是 USB。

## 画什么效果

- 只有 **单线笔画**（描边），没有填色、没有渐变、没有照片级写实。  
- 适合：简笔动物、植物、物品轮廓、简单场景、单线汉字/字母（折线拼字）。  
- 不适合：油画、水彩、复杂人像皮肤、大面积阴影、精细像素画。

## 用户怎么说效果好

优先这类说法：

- 「画一只侧脸简笔小猫」  
- 「画一辆自行车的侧视轮廓」  
- 「画一个站在树枝上的小鸟，线条简洁」

避免：

- 「画得越真越好 / 像照片一样」  
- 超长故事一次画完（应拆成「先画主角」）

## 工具清单（云端 MCP）

### hutuji_draw

- **何时用**：用户要画图、写字机出作品时。  
- **参数 description**：简短中文绘画主题（建议带「单线」「简笔」）。  
- **结果**：返回 G-code 下载 URL；设备再下载执行。  
- **注意**：一次只发起一幅；上一幅未完成不要连环狂点。

### hutuji_status

- **何时用**：用户问生成服务是否正常、有没有最近文件、LLM 配好了没。  
- **不要**用它代替设备实时笔位置查询（那是设备侧 status）。

### hutuji_preview_svg

- **何时用**：只要看看矢量草稿、不要马上出纸。  
- 调试用，不触发写字机运动。

## 工具清单（设备侧，S3）

### hutuji.status

查询与写字机的 Telnet 管道：是否连接、Grbl 是否就绪。

### hutuji.draw

参数 `url`：下载云端 G-code 并逐行转发给写字机。通常由云端 `hutuji_draw` 之后衔接。

### hutuji.abort

尝试中止当前任务。换纸动作一旦开始，物理上可能无法立刻停，需如实告知用户。

## 常见问题

**Q：为什么画出来是线稿？**  
A：机器是单线写字机，只能抬笔落笔描线。

**Q：能不能涂色？**  
A：不能。可改成「用线条表现轮廓」。

**Q：说了画怎么没动？**  
A：先查云端 `hutuji_status` 与设备 `hutuji.status`；可能未联网、未授权、缺纸或管道未就绪。

**Q：画太大/太复杂会怎样？**  
A：云端有大小与内容校验，过复杂可能失败；应改成更简的描述再试。

**Q：换纸中能急停吗？**  
A：换纸流程可能无法立即打断；完成后才会停，需提前说明。

## 禁止事项（助手必须遵守）

- 不向用户泄露 MCP token、API key、服务器密码。  
- 不声称能合并双芯片固件或改用 USB Host（已否决）。  
- 不编造「已出纸」——以工具返回与设备状态为准。
