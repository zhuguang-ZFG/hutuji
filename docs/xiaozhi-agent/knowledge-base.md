# 呼图机知识库（上传到小智「我的知识库」）

文档用途：供智能体检索，回答「能画什么、怎么画、不能做什么、工具怎么用」。

## 产品是什么

**呼图机**（hutuji）是一台 **AI 智能绘图机**：对它说话，它就帮你画出来——语音指令 → 云端 AI 生成绘图 → 写字机自动落笔，画完自动换纸，可以连续出作品。

它有两颗芯片协同工作：一颗负责听你说话和理解意图（ESP32-S3 小智），另一颗负责精确控制画笔运动和换纸（ESP32 Grbl）。两颗芯片通过 WiFi 通讯。

## 能画什么

呼图机擅长 **线条艺术**——用一支笔描绘轮廓和线条，风格类似速写、简笔画、线描插画。

### 特别适合画的

- **动物**：小猫、小狗、小鸟、兔子、鱼、蝴蝶等简笔轮廓
- **植物**：花朵、树木、叶子、仙人掌、向日葵的线描
- **日常物品**：自行车、杯子、房子、汽车、灯泡、雨伞
- **人物剪影**：侧脸轮廓、人物站姿/坐姿剪影
- **场景小品**：树枝上的鸟、窗边的花瓶、月亮和星星
- **文字书法**：汉字、英文字母（折线笔画风格）
- **几何图案**：星星、心形、雪花、简单曼陀罗

### 画不了的

- 照片级写实（没有阴影渐变）
- 填色/涂色（只有线条）
- 油画/水彩效果
- 大面积色块
- 精细像素画

遇到画不了的需求时，建议用户换成线条风格的替代方案。

## 用户怎么说效果好

### 好的说法（推荐）

- 「画一只小猫」→ AI 自动补全为合适的线描风格
- 「画朵向日葵」
- 「画个自行车」
- 「画一只站在树枝上的小鸟」
- 「写个大大的福字」
- 「画个简笔画的小房子，旁边有棵树」
- 「画一条鱼，侧面的」

### 不太好的说法

- 「画得像照片一样真实」→ 建议改成线描风格
- 一次要求画整个故事 → 建议拆成一幅一幅来
- 含大量参数/色值 → 提醒只有黑白线条

### AI 怎么补全

用户说的往往很简短，AI 应补全成适合线描绘图的描述：
- 「画个猫」→ description：`单线简笔小猫，侧面站姿，留白构图`
- 「来朵花」→ description：`一朵盛开的花朵线描，花瓣舒展`
- 「画条鱼」→ description：`单线简笔小鱼，侧面游动姿态`

## 工具清单（云端 MCP）

### hutuji_draw

- **何时用**：用户要画图、出作品时。  
- **参数 description**：简短中文绘画主题（建议带「单线」「简笔」「线描」）。  
- **结果**：返回 G-code 下载 URL；设备再下载执行。  
- **注意**：一次只发起一幅；上一幅未完成不要连续触发。

### hutuji_status

- **何时用**：用户问云端生成服务是否正常。  
- **不要**用它代替设备实时状态查询（那是设备侧 `hutuji.status`）。

### hutuji_preview_svg

- **何时用**：只看矢量草稿效果、不要马上出纸。  
- 调试用，不触发写字机运动。

## 工具清单（设备侧，S3）

### hutuji.status

查询设备与写字机的连接状态：是否连通、Grbl 是否就绪、是否已授权、当前任务状态。

### hutuji.draw

参数 `url`：下载云端 G-code 并逐行转发给写字机。通常由云端 `hutuji_draw` 返回 URL 后自动衔接。

### hutuji.abort

尝试中止当前任务。换纸动作一旦开始，物理上可能无法立刻停，需如实告知用户。

## 常见问题

**Q：为什么画出来都是线条？**  
A：呼图机是线描绘图机，用一支笔勾勒轮廓，这就是它的风格特色——像速写和简笔画。

**Q：能不能画彩色的？**  
A：目前只支持单色线条。可以换不同颜色的笔芯，但同一幅画只有一种颜色。

**Q：我说了画，它怎么没动？**  
A：可能是：①云端服务还没准备好（查 `hutuji_status`）；②设备没连上写字机（查 `hutuji.status`）；③缺纸了；④写字机未授权。

**Q：画太复杂会怎样？**  
A：云端有内容校验，太复杂可能失败。建议换个更简洁的描述再试。

**Q：正在画能不能停？**  
A：可以说「停下」。但如果正在换纸，需要等换纸完成才能停。

**Q：它能连续画很多张吗？**  
A：可以！画完一张自动换纸，说下一个主题就继续画。

**Q：画的大小怎么控制？**  
A：画面大小由云端自动适配纸张，用户无需指定尺寸。

## 禁止事项（助手必须遵守）

- 不向用户泄露 MCP token、API key、服务器密码。  
- 不声称能合并双芯片固件或改用 USB Host（已否决）。  
- 不编造「已出纸」——以工具返回与设备状态为准。  
- 不承诺填色、渐变、写实等超出能力的效果。
