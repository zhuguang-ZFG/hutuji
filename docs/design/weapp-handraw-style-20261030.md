# 全端 HandRaw Style 奶油卖萌视觉改造（2026-10-30）

## 目标

在不改变登录、绑机、配网、生成、发送、控制、OTA、纸张与运动状态机的前提下，把小程序、公开 Portal、运营后台、知识库后台和量产 Freenove 小派 S3 统一为让人一眼记住的可爱卖萌手绘体验。

视觉参考来自 [yang0/handraw-style](https://github.com/yang0/handraw-style)。根据用户补充的「印象深刻、美观、可爱卖萌」要求，从全库重新动态选定 **FH-031 小红书奶油手绘**，主题色使用 **C-34 奶油白 + C-21 珊瑚粉 + C-09 薄荷绿 + C-27 那不勒斯黄**。奶油留白承载内容，珊瑚粉负责主动作和腮红，薄荷绿负责在线/成功反馈，那不勒斯黄负责星星与提醒；避免把“可爱”简化成整屏粉色。

项目许可要求二次开发保留原作者与原仓库地址，因此小程序「我的」页及三套网页均保留可见致谢与原项目入口，README 同步登记来源。

## 小程序实现范围

- `weapp/styles/handdraw-theme.wxss`：集中维护奶油纸面、珊瑚粉主动作、薄荷绿成功态、那不勒斯黄点缀和暖莓文字；不引入纹理位图，避免增加包体和降低文字对比度。
- 首页、控制、历史、我的四条主路径复用 CSS/WXML 原生绘制的「小派」软萌脸：猫耳、眨眼、腮红、微笑和漂浮动画均不依赖位图资源。
- 聊小派页沿用紧凑对话布局，但头像同步猫耳、莓色大眼与奶油承载面；欢迎语改为「今天想和小派画什么？」。
- `app.json`、`app.wxss`：导航栏、TabBar、全局背景与卡片令牌统一为奶油手绘主题。
- 绑定、配网、升级、分享、纸张、画板、小派设置和精品图库由全局覆盖层统一，不改页面交互和接口参数。
- 所有原本显式配置 `#0B0C13` 的页面背景改为 `#FFF7ED`，并使用深色下拉刷新文字，消除跳页和下拉时的黑底闪烁。
- 小程序候选版本由 0.3.33 调整为 0.3.34；未执行上传、提审或发布。

## 小派 S3 实现范围

- 目标是量产 `freenove-esp32s3-display-2.8-lcd`；不改变板型、GPIO、触摸区域、控件树、回调、OTA 或写字机协议。
- S3 视觉候选使用唯一新版本 `hutuji.1.0.54`，避免与已存在但内容不同的 `1.0.53` 镜像同号；未发布、未刷机、未 OTA。
- S3 产品提交 `bbc1ec9` 已推送 `origin/feat/hutuji-usb-pipe`；镜像由该提交同态源码构建。
- 设备历史上强制保存主题键 `dark`。为避免 NVS 迁移，保留键名，只把该主题的量产色令牌改为 FH-031 奶油白、暖莓文字、珊瑚粉动作、薄荷绿成功和柔黄提醒。
- 现有 Kawaii 大眼桌宠保留 17 种情绪、眨眼、聆听、说话与高压任务冻结机制；新增可配置舞台底色，Freenove 使用暖莓色 `#6B4E5E`，其他板仍默认黑底。
- 眼睛、嘴部 RGB565 画布与父容器共用同一个舞台底色，避免奶油界面中出现纯黑矩形接缝；字幕条回到奶油卡片语义。
- 禁用按钮改用主题自身的浅色令牌，不再硬编码深蓝灰；安全状态色仍独立，不用粉色覆盖错误/警告/成功含义。

## Portal 与管理后台实现范围

- 公开 Portal 新增 `cream` 主题并设为默认，保留青墨、天空、苔绿、暮色供用户主动切换；主题存储键升级为 `hutuji-draw-theme-v2`，让既有用户首次进入也能看到新版默认面，之后仍保存其选择。
- 「呼图云」品牌头改为「丹青 · 小派画画屋」，以纯 HTML/CSS 绘制猫耳、大眼、微笑和星星，不引入位图或外部字体。
- 运营后台从深色暮色改为奶油纸面，小派头像与公开 Portal 同构；按钮、表格、设置卡和状态色仍保留原有业务层级。
- 知识库后台从蓝白工具界面改为「小派知识画册」，共享奶油白、珊瑚粉、薄荷绿、柔黄和暖莓文字；登录页与工作台各有同一品牌标记。
- 三套网页均显示 HandRaw Style / yang0 致谢及原仓库入口；不更改任何 API、鉴权、写请求防重、焦点管理、超时或错误处理逻辑。

## 安全边界

- 不复制上游参考图、画廊或提示词数据进小程序包，仅使用视觉原则与配色令牌。
- 不修改后端、设备协议、运动参数、OTA 判断、账号和页面代次逻辑。
- S3 不改 GPIO、音频、网络、Telnet、MCP 工具或写字机任务状态机；只改显示主题与现有桌宠的绘制底色。
- 网页不引入 CDN、远程脚本或媒体资产；保留原来的 DOM id、表单、事件和请求路径。
- 不把本地候选写成已上传、已刷机、已 OTA 或平台已发布；发布状态仍以 `docs/release-readiness.md` 为准。
