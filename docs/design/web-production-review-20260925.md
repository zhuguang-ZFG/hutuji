用户追加授权「各种网页也要进行各种改进优化，更能适用于量产；参考行业惯例达到量产水平」。仓内产品 HTML 共三张：买家传图门户、运营后台、知识库后台；另检查微信小程序共享网络入口。量产交付仍是 `massprod/nopaper-1.3a` 无自动换纸，不改机型、运动或换纸契约。本批只修改本地源码，未提交、部署、发布或刷机。

## 多轮确认与修复

第一轮真实浏览器先复现六项失败，再修复并全部通过：

1. 后台封禁 prompt 返回 null 仍被默认理由代替并执行。现在取消即结束，后台写请求按资源防重；用户字段、会话名、统计和配置文案统一 HTML 转义，路径单独编码。
2. 门户慢图片压缩覆盖新文件；新选文件仍保留旧可发送任务。现在文件选择/任务结果分别有代次，新选择立即清理旧产物；上传与生图共用忙状态，旧结果不更新新选择。
3. 门户发送、保存可重复触发。现在各自占位；第三轮扩展为图库和预览共用设备发送占位，刷新列表重建按钮也不能绕过。旧保存回包不能关闭新编辑内容。
4. 关闭的上传面板仅 CSS 平移，Tab 仍可进入。现在关闭时 inert，打开时背景不可聚焦，焦点进入并限制在弹窗内，Escape 关闭并恢复触发点；文件选择支持 Enter/空格。
5. 后台加载串行，一个模块失败阻断其余模块。现在独立加载并汇总可重试错误；设置/备注加载失败时禁止保存空表，保存后的读回失败仍保持禁用。

第二轮补慢网/乱序回归，14项通过：

- 门户临时离线保留已登录界面，仅当前 `/auth/me` 的401切回登录；图库和身份刷新忽略旧回包，增加显式刷新入口。请求统一超时、异常响应和中文错误，写操作结果不确定时提示先核对状态，绝不自动重试。
- 后台用户详情/会话明细按选择代次更新，异步失败有可见反馈；登录清密码，退出失败可见；移除无引用会话状态和路径变量。
- 小程序拒绝3xx、缺失状态码、200 HTML/空响应和上传JSON解析失败；写请求断网/超时不再暗示“肯定没执行”。保留旧401按会话代次隔离和游客浏览不强跳登录。

第三、四轮覆盖遗漏运营入口和移动体验，最终24项通过：

- 手机运营后台原 `.table-wrap` 统一隐藏，误把设备绑定表也隐藏。仅隐藏已有卡片替代的用户表，设备表可横向滚动和键盘聚焦；数字输入统一样式、移动按钮至少44px、焦点轮廓和辅助文字对比度改善。
- 知识库导入/提交网络异常曾使 loading 永不结束；统一返回可处理错误并设置超时。提交、删除、启用切换与批量操作占用同一忙状态；处理期间不能关闭或切换编辑目标。未保存草稿关闭需确认，弹窗焦点受限。先新增三项失败回归，修复后全部通过。
- 知识库启动与分类筛选原重复拉列表。复用一次完整列表，分类在浏览器过滤；刷新合并FAQ和发布历史读取，删除失效勾选，历史读取失败可见。
- 最终复审补后台会话代次：重新登录不被旧模块加载阻塞，旧401不能退出新会话，旧读取不能回填新面板。
