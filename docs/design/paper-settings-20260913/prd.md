# 纸张、设备行程与创作体验

用户要求小派设备和小程序支持 A4/A3/A2、XY 轴交换，文字、笔顺、图片和手绘均按设置生成，并完成设计、实现、验证与上线。用户已明确：大纸张用于其他大行程机器，按每台设备实际行程校验；两个界面的体验均需改善。继续前批三仓故障修复，不撤销已有工作。

## 需求与验收

- R1：按设备保存纸张预设、自定义宽高、横竖版、留边与 XY 交换。小程序可编辑，设备屏幕可选预设、方向与交换，并显示实际可绘制范围。换账号、换设备、迟到回包不得串配置。
- R2：纸张与机器可绘制行程分别建模。默认 paper 保留 277/190mm、nopaper 保留 205/290mm；大行程只能由用户明确填写已核对的可绘制范围，不读取厂商 `$130/$131` 自动扩边，也不改这些 Grbl 设置。纸张有效区域在轴交换之后必须装入机器范围。
- R3：图片、照片风格、文字、笔顺、文档、表格、语音及手绘共用不可变配置快照。大纸张重新排版而非将文字整体拉大；字号、笔顺顺序、描摹容差、文件 512KiB 与 F/Z 契约不变。
- R4：生成去重、G-code 缓存和队列包含完整配置。文件服务按该产物的特定配置复核；保存、分享、重发保留快照。设置变化后旧预览不能静默变换或发给不匹配的机器。
- R5：小派新固件在下载阶段核对产物配置与本机配置；旧固件仅沿用既有默认行为，新增设置明确提示需要升级。配置修改不得打断进行中的运动或预览。
- R6：手绘增加实时对称/放射创作、可编辑图形素材和绘制回放，保留原有画笔、整笔橡皮、形状、撤销重做、缩放和平移。画面与 SVG 同源，草稿按账号保存，换纸张需明确适配；不会自动向设备发送。
- R7：继续完成设备小屏布局、聊天输入、录音、控制等待和三仓隐藏问题修复。手机手势、实屏和纸面验证分别登记，不能由 host 或截图代替。

## 验证标准

覆盖 A4/A3/A2、自定义、横竖、XY 两向、两种旧机型、不同大行程、非法值、整圆/圆弧越界、并发配置隔离与配置过期。使用真实 vpype 验证图片/文字/笔顺/手绘输出；多页文字同字号，nopaper 多页限制保持。完整 portal、Node、MCP、S3 host/三板构建、Grbl host/双构建、fz standard 与枢纽 full 按改动面收口。

## 范围边界

不改 Grbl 运动、换纸、授权、GPIO、速度与 `$130/$131`。不以纸张选择扩大全局旧机型限幅。未接入的大行程机器只能取得软件验证，不能宣称其纸面或实体行程已经验证。公众号独立草稿、用户杂物及现有 `.gitignore` 修改保留。
