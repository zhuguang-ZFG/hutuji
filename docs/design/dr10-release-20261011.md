## 用户追加：运行/暂停时的电机声音

用户定位在写字机电机/运动机构附近，并确认暂停不动也响。最后一项试笔按既有规则不自动释放，与此时的持续声一致。在固定身份、连续两次Idle原点后，人工单次`$MD`得到ok；用户先反馈“明显变小，但还有”，随后反馈“我现在似乎已经听不到声音了”。只记录这一现场对照，没有采集声压、相电流或驱动器波形；不将它写成运动中静音已解决。

量产固件按HR4988的STEP/DIR及GPIO25共用使能配置，当前机型头没有运行/保持电流配置通道。普通MK38资料中的GPIO25电流DAC属于另一套机型映射，不能移植到这台量产机。暂停需要保持位置；没有改$1、驱动电流、引脚或在Hold中断使能。当前机器在原点释放后保持安静。若要降低运行/暂停保持噪声，还需针对实板驱动及电流设定取证，不据源码名称或主观“电流声”直接调整Vref。
