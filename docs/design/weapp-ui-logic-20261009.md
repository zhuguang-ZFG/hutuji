# 小程序 UI 与逻辑续审（2026-10-09）

## 范围与验收

沿用深色与青色视觉体系，限创作、精品图库、收藏和控制页面。协议依据为 §10.4.9/§10.4.14/§10.4.21/§10.4.23；不改后端、固件或运动行为。

1. 分享准备按作品版本与账号隔离；切页后能恢复，准备失败有重试入口，未就绪的作品分享按钮不打开首页分享。
2. 精修等待以同一作品首次等待后的 300000ms 为截止；即使请求无应答也结束等待，不在截止点新发轮询，迟到结果不改终态。主动核对仍可读取最终结果。
3. 图库账号查询暂时失败保留同账号已加载列表、分类与游标；重试账号查询后恢复，目录或翻页错误仍各自重试；换账号清除旧内容。
4. 收藏刷新优先当前筛选结果预览，旧视口回调失效；错误页不同时显示空收藏或空筛选提示。
5. 预览操作分主次、翻页热区增大；收藏标题可读、操作反馈明确；图库错误靠近分类；设备离线时给检查步骤与刷新入口，暂停/停止等已有能力判断保留。
