## 开箱

1. 主机、电源、【笔/纸】、本说明书。
2. 按机身方向标识稳固放置，固定一张纸，留出运动空间。
3. 按安装说明固定笔夹、确认原点，再接电；不要手推已使能的轴。

## 联网

1. 在小派长按进入配网，微信扫描屏幕二维码，按页面提示登录/绑定手机号并接入2.4GHz Wi‑Fi。小派会为本套写字机配网；两板须在同一路由器且可互访。
2. 等待指示灯/语音提示就绪。
3. 若提示无法连接：检查网络及路由器设备隔离设置，按提示重试；身份不匹配或反复失败时提供机身SN联系支持。

## 使用

1. 用语音说出绘图需求（例如：“画一只简笔画小猫”）。
2. 核对预览与纸张后开始绘制；绘制中请勿断电、勿强拉纸张。
3. 一页结束后等待笔抬起、机器归位停稳，再手动取换纸。本量产型号没有自动换纸机构。
4. 暂停可原位继续；停止会排空在途命令并归位，并非即时急停。更新中勿断电，结果不明先查看状态。

## 请勿

- 未授权或未就绪时强行出图。
- 绘制或升级过程中拔电（紧急情况除外）。
- 使用超出说明书的纸张厚度/尺寸。
- 自行拆解运动机构（保修免责见【保修条款】）。

## 异常

| 现象 | 你可以做的 |
|------|------------|
| 无响应 | 检查电源与 Wi‑Fi；重启一次 |
| 纸张偏移/笔迹不清 | 停稳后重新固定纸张、核对笔高 |
| 画到一半停止 | 勿强行拉纸；联系支持并保留批次号 |
| 换路由器/转让设备 | 重新扫码配网；转让先在设备管理中解绑，恢复出厂不代表所有权已转让 |
