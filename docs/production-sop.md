# 小批量生产 SOP

> 2026-10-10：本流程适用于量产nopaper/Freenove；替代旧自动换纸首件要求。前置为适用的bringup证据、固定发布包和本批签核；换纸机重回交付时另开流程。工具入口与示例见[工位手册](../production/README.md)。

## 总流程

1. 首件确认（First Article）
2. 逐台功能检验
3. 老化 / 抽样故障注入
4. 包装与附件
5. 放行签字（对照 `release-checklist.md` + `compliance.md`）

每台填 `docs/templates/device-test-record.md`；每批填 `docs/templates/release-manifest.md`。

## 1. 首件

| 项 | 判据 | 记录 |
|----|------|------|
| 三仓版本 | 与本批 manifest 一致 | commit / 固件 SHA256 |
| 写字机授权 | `[License] Authorized` | ChipID（按隐私政策处理） |
| Telnet | S3 `connected/ready/authorized` | IP、设备号 |
| 双板身份 | 工厂SN、S3 MAC、Grbl STA/AP MAC与台账一致；同网多机不串台 | factory_paired、paired_grbl_mac和对照日志 |
| 量产参数 | 速度6000/6000/1200、加速度3000/3000/3000；其余机设保持 | 全表读回及配方SHA |
| 语音出图 | 标准图可见、完成归位、确认电机释放；人工取换纸 | 照片/日志路径 |
| 云端 | 阿里主、京东热备；本批公网入口可达 | 真产物下载+CRC头、部署SHA |

首件不过 → 停线，不进入批量。

## 2. 逐台功能（最低）

| # | 检查 | 通过 |
|---|------|------|
| 1 | 上电、串口 banner / `$I` | 有 `[VER:]` |
| 2 | 授权 | Authorized |
| 3 | S3 联网 + 探活 | status 三真 |
| 4 | 一次短图出纸 | 纸面可见、无撞机 |
| 5 | 停止/再次出图 | 停稳归位后可重新绘制；nopaper不要求自动换纸 |
| 6 | 外观/标签/序列号 | 与标签规范一致 |

失败台隔离，记偏差；修复后**整表重测**，不得只测失败项宣称全过。

## 3. 老化与抽样（2026-10-10用户批准首批试行门槛）

| 项 | 首批试行判据 | 记录 |
|----|-------------------|------|
| 通电老化 | 每台≥4小时，零异常重启 | 开始/结束时间与原始日志 |
| 连续出图页数 | 每台≥30次标准图，人工换纸 | 每次任务结果、零失步/漏笔 |
| 纸面 | 20mm标准图尺寸误差≤1mm、零漏笔/失步 | 原始测量与照片，不能只写pass |
| 抽样故障 | 每批至少 1 台做拔电/abort 各 1 次（对照阶段 8） | 须留日志 |

## 4. 包装

- 主机、电源、说明书（客户版 quickstart）、合格证/序列号
- 开源许可证通知（见 `compliance.md`）随附或可下载说明
- 缓冲与防潮按硬件规范（待 BOM 负责人填）

## 5. 放行

先运行工位工具`status`检查缺项、`release`验证证据摘要与数值门槛，再由生产、研发、QA、发布负责人在manifest签字。开放偏差必须有风险接受人与截止日期。返修新代次撤销旧合格状态，整表重测。

软件模拟/构建不填入实物合格记录；试行门槛批准不等于首批已经通过。每日备份台账和证据目录并抽验恢复。型号、主体、售后联系方式仍待用户提供，客户资料不能带占位印刷。
