# 下载工具本机配置

`esp32/` 下三份配置是本机下载工具生成的状态。当前没有选择镜像、串口或记录设备 MAC，工具结束方式为 `no_reset`；它们不构成量产烧录配方，也不代表 S3 的板型和分区配置。

产线使用 `docs/bringup-sop.md` 与 `docs/release-readiness.md` 的已验证镜像和台账：先读 MAC 核对板型，核对镜像 SHA 和烧录范围，按台账决定是否保留 NVS，结束后执行硬复位并验证启动版本、屏幕和扫码入口。COM 口与编译期 SKU 不能代替硬件身份。

这里不保存密钥，不启用安全启动、加密或 eFuse 烧写。涉及不可逆配置应独立形成板型明确的生产方案和验证记录。不要把空白工具状态打入发布包。
