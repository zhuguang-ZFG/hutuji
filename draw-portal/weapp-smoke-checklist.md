# 动力巢科技 v0.3.13 真机冒烟清单（提审/发版前逐项打勾）

> 用途：微信开发者工具「预览」二维码 → 真机逐项过。任何一项不过，先修再提审。
> 版本基线：2026-09-13 控制页、录音、作品列表与会话隔离修复；开发者工具和手机实测分别记录，未做的项目不打勾。
> 前置：量产机已绑定、设备在线，先核对控制页页脚为本次版本。

## 0. 登录与门禁

- [ ] 首次打开 → 微信登录 → 手机号授权 → 进入「创作」页
- [ ] 未绑设备时固件页提示「请先绑定设备」并跳绑定页

## 1. 创作（AI 画 / 写字 / 笔顺 / 传图 / 拍照）

- [ ] 输入「画一只小猫」→ 生成成功 → 预览卡出现（含「AI 正在画」精修等待态→精修版上屏）
- [ ] 输入文章文字 → 写字 → 多页卡显示页数；发送后设备开始写
- [ ] 输入汉字 → 笔顺 → 逐字面板上屏
- [ ] 相册选图 → 转换 → 预览；拍照同链
- [ ] 选择器暂时隐藏页面后，所选文件仍可转换；取消选择后能重新打开
- [ ] 上传 docx/xlsx → 多页错峰可发
- [ ] **首次点「生成」出现订阅消息授权弹窗；点「允许」后等生成完成，微信「服务通知」收到「生成成功」通知**；拒绝授权则不再弹（下次提交再弹）
- [ ] 生成失败场景（飞行模式）→ 弹失败白话；不闪退、不卡死按钮

## 2. 分享

- [ ] 出结果后点右上角「…→转发」→ 卡片带预览图
- [ ] 接收者（另一微信账号）点开 → 落地页显示预览 + 「我也要画」→ 跳创作页
- [ ] 接收者无「动力巢科技」使用记录也能打开（免登录落地页）
- [ ] 分享链接 24h 后失效（可等待或改短 TTL 验证）

## 3. 历史

- [ ] 列表按 全部 / AI 画 / 写字 / 笔顺 筛选正确
- [ ] AI 画条目点「重画」→ 确认 → 生成 → 跳创作页并上屏新结果
- [ ] 传图条目无「重画」钮
- [ ] 发送 → 设备开画；删除 → 列表移除
- [ ] 筛选后长按删除只移除选中的作品；图片加载完成后当前筛选列表立即显示
- [ ] 空收藏 → 空状态文案 + 引导；筛选无结果 → 「该类暂无作品」

## 4. 小派聊天

- [ ] 文字对话正常回复；违规词被拦回安全话术
- [ ] 语音「画一只猫」→ 预览卡 → 「开始画」→ 设备画
- [ ] 按住说话首次弹订阅授权（同 1）
- [ ] 极快按下松开不持续录音；录音中切页立即停止；退出后旧转写不再触发设备动作
- [ ] 文字回复/画图生成中切页再回来可见结果，连续点击不重复提交

## 5. 控制与固件

- [ ] 控制页时间线：空闲 → 出图中 → 结束；暂停/继续/停止可用
- [ ] 正常进页读到 X/Y/Z=10000/10000/1200；X、Y、Z 各自拖动只改本轴，验证后恢复原值
- [ ] 初始读取时显示加载状态；断网/读取失败有刷新入口，不一直显示无原因的灰色滑块
- [ ] 固件页「检查更新」→「已是最新版本」绿色提示（不再弹「HTTP 504」类报错）
- [ ] 设备离线时点检查 → 「连接不稳/超时」类温和文案，无生僻错误码
- [ ] （有新版本时）点升级 → 进度条走完 → 「升级成功」；中途断网再恢复 → 页面继续轮询并收口，不卡死
