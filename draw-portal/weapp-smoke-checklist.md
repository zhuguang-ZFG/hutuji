## 0. 登录与门禁

- [ ] 首次打开 → 微信登录 → 手机号授权 → 进入「创作」页
- [ ] 未绑设备时固件页提示「请先绑定设备」并跳绑定页

## 1. 创作（AI 画 / 写字 / 笔顺 / 传图 / 拍照）

- [ ] 输入「画一只小猫」→ 生成成功 → 预览卡出现（含「AI 正在画」精修等待态→精修版上屏）
- [ ] 输入文章文字 → 写字 → 多页卡显示页数；发送后设备开始写
- [ ] 输入汉字 → 笔顺 → 逐字面板上屏
- [ ] 相册选图 → 转换 → 预览；拍照同链
- [ ] 上传 docx/xlsx → 多页错峰可发
- [ ] **首次点「生成」出现订阅消息授权弹窗；点「允许」后等生成完成，微信「服务通知」收到「生成成功」通知**；拒绝授权则不再弹（下次提交再弹）
- [ ] 生成失败场景（飞行模式）→ 弹失败白话；不闪退、不卡死按钮

## 2. 分享

- [ ] 出结果后点右上角「…→转发」→ 卡片带预览图
- [ ] 接收者（另一微信账号）点开 → 落地页显示预览 + 「我也要画」→ 跳创作页
- [ ] 接收者无「动力巢科技」使用记录也能打开（免登录落地页）
- [ ] 分享链接 24h 后失效（可等待或改短 TTL 验证）

- [ ] 传图条目无「重画」钮
- [ ] 发送 → 设备开画；删除 → 列表移除
- [ ] 空收藏 → 空状态文案 + 引导；筛选无结果 → 「该类暂无作品」
